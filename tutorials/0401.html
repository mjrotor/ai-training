What is a Tool?

Learn about what is a tool?.

What is a Tool?

In the world of AI agents, a tool is a function or capability that an agent can use to interact with the outside world. Think of tools as the agent's hands and eyes — they allow the agent to do things beyond just generating text.

Without tools, an AI agent is limited to only what it learned during training. With tools, it can:

  • Search the web
  • Read or write files
  • Call APIs
  • Perform calculations
  • Send emails or messages

Why Do Agents Need Tools?

Imagine asking a friend to book a flight for you. They can't do it alone — they need access to a computer, a website, or a phone. Similarly, an AI agent needs tools to take actions in the real world.

Key Idea: Tools bridge the gap between an agent's reasoning and real-world actions.

Types of Tools

Tools come in many forms. Here are common categories:

Tool Type Purpose Example
Web Search Find current information Google Search API
File I/O Read/write files open(), read_csv()
Calculator Perform math eval(), math module
API Client Call external services requests.get()
Database Store/retrieve data SQLite, PostgreSQL

How Tools Work in Code

Let’s look at a simple example. Suppose we want to give our agent a tool that fetches the current weather.

import requests

def get_weather(city):
    url = f"https://api.weatherapi.com/v1/current.json?key=YOUR_KEY&q={city}"
    response = requests.get(url)
    data = response.json()
    return data['current']['temp_c']

# Example usage
temp = get_weather("London")
print(f"The temperature in London is {temp}°C")
Tip: Always wrap tool logic in functions so the agent can call them easily.

Defining Tools for an Agent

Most agent frameworks expect tools to be defined with clear names, descriptions, and input parameters. Here’s how you might define a tool in a typical setup:

weather_tool = {
    "name": "get_weather",
    "description": "Returns the current temperature in Celsius for a given city.",
    "parameters": {
        "type": "object",
        "properties": {
            "city": {
                "type": "string",
                "description": "The name of the city."
            }
        },
        "required": ["city"]
    }
}

This structure helps the agent understand when and how to use the tool.

Warning: Poorly described tools can confuse the agent. Always write clear, specific descriptions.

Exercise: Create Your Own Tool

Exercise

Write a Python function called convert_currency(amount, from_currency, to_currency) that uses a free API (like exchangerate.host) to convert an amount from one currency to another.

Your function should return the converted amount as a float.

import requests

def convert_currency(amount, from_currency, to_currency):
    url = f"https://api.exchangerate.host/convert?from={from_currency}&to={to_currency}&amount={amount}"
    response = requests.get(url)
    data = response.json()
    return data['result']

# Example
converted = convert_currency(100, "USD", "EUR")
print(f"100 USD = {converted:.2f} EUR")

Key Takeaways

  • Tools extend an AI agent’s capabilities beyond text generation.
  • Common tools include web search, file operations, calculators, and API clients.
  • Tools should be well-documented with clear names, descriptions, and parameter schemas.
  • Poor tool design leads to agent confusion and errors.
