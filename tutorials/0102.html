The Agent Loop: How AI Agents Think and Act

In this lesson, we'll explore the fundamental concept that powers every AI agent: the agent loop. This is the repeating cycle that allows an agent to perceive its environment, make decisions, and take actions to achieve goals.

What is an Agent?

An AI agent is a system that can:

  • Perceive its environment through sensors or inputs
  • Reason about what it perceives
  • Act to change its environment
  • Learn from the results of its actions
Think of it like this: A self-driving car is an agent. It perceives the road (cameras, sensors), reasons about what it sees (is that a pedestrian?), acts (brake or steer), and learns from outcomes.

The Four Stages of the Agent Loop

Every agent operates in a continuous cycle with four key stages:

  1. Perceive — Gather information from the environment
  2. Reason — Process information and decide what to do
  3. Act — Execute the chosen action
  4. Observe — See the result of the action

Then the loop repeats! This cycle continues until the agent achieves its goal or encounters a stopping condition.

A Simple Python Example

Let's build a basic agent loop in Python. This agent will try to guess a secret number by making guesses and receiving feedback.

def simple_guessing_agent(secret_number, max_attempts=10):
    """A simple agent that guesses a number using feedback."""
    low = 1
    high = 100
    
    for attempt in range(max_attempts):
        # REASON: Make a guess (using binary search strategy)
        guess = (low + high) // 2
        print(f"Attempt {attempt + 1}: Guessing {guess}")
        
        # OBSERVE: Get feedback from environment
        if guess == secret_number:
            print(f"Found it! The number was {guess}")
            return guess
        elif guess < secret_number:
            print("Too low!")
            low = guess + 1  # Update knowledge
        else:
            print("Too high!")
            high = guess - 1  # Update knowledge
    
    print("Max attempts reached!")
    return None

# Run the agent
simple_guessing_agent(secret_number=73)
Notice the pattern: The agent doesn't just guess randomly. It reasons using a strategy (binary search) and updates its knowledge after each attempt. This is the essence of intelligent behavior!

Building a More Sophisticated Agent

Let's create a more complete agent that can handle multiple types of tasks. This agent will have memory and can choose different strategies based on the situation.

class TaskAgent:
    """An agent with memory and multiple strategies."""
    
    def __init__(self):
        self.memory = []  # Remember past experiences
        self.strategies = {
            'search': self._search_strategy,
            'calculate': self._calculate_strategy,
            'default': self._default_strategy
        }
    
    def perceive(self, task):
        """Analyze the task to understand what's needed."""
        self.memory.append(f"Received task: {task}")
        
        # Determine which strategy to use
        if 'find' in task.lower() or 'search' in task.lower():
            return 'search'
        elif 'calculate' in task.lower() or 'math' in task.lower():
            return 'calculate'
        else:
            return 'default'
    
    def reason(self, strategy_key):
        """Choose the best strategy based on perception."""
        return self.strategies[strategy_key]
    
    def act(self, strategy, task):
        """Execute the chosen strategy."""
        result = strategy(task)
        self.memory.append(f"Completed: {task} -> {result}")
        return result
    
    def run(self, task):
        """Execute one full loop cycle."""
        strategy_key = self.perceive(task)
        strategy = self.reason(strategy_key)
        return self.act(strategy, task)
    
    def _search_strategy(self, task):
        return f"Searching for: {task}"
    
    def _calculate_strategy(self, task):
        return f"Calculating result for: {task}"
    
    def _default_strategy(self, task):
        return f"Processing task: {task}"

# Create and run the agent
agent = TaskAgent()
print(agent.run("Find the capital of France"))
print(agent.run("Calculate 2 + 2"))
print(agent.run("Write a poem"))
Common mistake: Don't confuse an agent with a simple function. An agent has state (memory), can adapt its behavior, and operates in a loop. A function just takes input and returns output.

Exercise: Build Your Own Agent

Now it's your turn! Create a simple agent that helps a user find books in a library.

Exercise: Library Book Finder Agent

Create a LibraryAgent class that:

  1. Has a list of available books (at least 5)
  2. Can perceive a user's search query
  3. Can reason about which books match the query
  4. Can act by returning matching books
  5. Remembers the last 3 searches in memory

Your agent should handle searches by title, author, or genre.

class LibraryAgent:
    def __init__(self):
        self.books = [
            {"title": "The Great Gatsby", "author": "F. Scott Fitzgerald", "genre": "fiction"},
            {"title": "1984", "author": "George Orwell", "genre": "dystopian"},
            {"title": "To Kill a Mockingbird", "author": "Harper Lee", "genre": "fiction"},
            {"title": "A Brief History of Time", "author": "Stephen Hawking", "genre": "science"},
            {"title": "The Hobbit", "author": "J.R.R. Tolkien", "genre": "fantasy"}
        ]
        self.memory = []
        self.max_memory = 3
    
    def perceive(self, query):
        """Analyze the search query."""
        query = query.lower()
        if 'author:' in query:
            return 'author', query.replace('author:', '').strip()
        elif 'genre:' in query:
            return 'genre', query.replace('genre:', '').strip()
        else:
            return 'title', query.strip()
    
    def reason(self, search_type, search_term):
        """Find matching books."""
        matches = []
        for book in self.books:
            if search_term in book[search_type].lower():
                matches.append(book)
        return matches
    
    def act(self, matches, search_term):
        """Return results and update memory."""
        # Update memory (keep only last 3)
        self.memory.append(search_term)
        if len(self.memory) > self.max_memory:
            self.memory.pop(0)
        
        if matches:
            return f"Found {len(matches)} book(s): {[b['title'] for b in matches]}"
        return f"No books found for '{search_term}'"
    
    def search(self, query):
        """Run one agent loop cycle."""
        search_type, search_term = self.perceive(query)
        matches = self.reason(search_type, search_term)
        return self.act(matches, search_term)

# Test the agent
agent = LibraryAgent()
print(agent.search("fiction"))
print(agent.search("author: orwell"))
print(agent.search("genre: fantasy"))
print(f"Search history: {agent.memory}")

Key Takeaways

  • An agent is a system that perceives, reasons, acts, and learns from its environment
  • The agent loop (Perceive → Reason → Act → Observe) is the fundamental pattern
  • Agents can have memory to remember past experiences and improve over time
  • Different strategies can be used depending on the situation
  • More sophisticated agents maintain an internal model of the world
  • The key difference between an agent and a simple function is state and adaptability
