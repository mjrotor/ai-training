Adding Calendar & Email Tools

In this lesson, you'll learn how to extend your AI agent with calendar and email capabilities. These tools allow your agent to schedule meetings, send reminders, and manage communications — making it far more useful in real-world scenarios.

Why Add Tools to Your Agent?

An AI agent without tools is like a person without hands — it can think and reason, but it can't do anything. By adding tools, you give your agent the ability to:

  • Interact with external services (like Google Calendar or Gmail)
  • Perform actions based on user requests
  • Retrieve and update real-world data
What is a "tool"? In the context of AI agents, a tool is a function that the agent can call to perform a specific action. Think of it as giving your agent a new skill.

Understanding the Tool Pattern

Every tool in your agent follows a simple pattern:

  1. Define the function — Write a Python function that does something useful
  2. Describe the tool — Give the agent information about what the tool does
  3. Register the tool — Add it to your agent's list of available tools

Basic Tool Structure

def tool_name(parameter: str) -> str:
    """Description of what this tool does.
    
    Args:
        parameter: Description of the parameter
    
    Returns:
        A string describing the result
    """
    # Do something useful
    result = perform_action(parameter)
    return result

Building a Calendar Tool

Let's start by creating a tool that can add events to a calendar. For this example, we'll use a simple in-memory calendar, but the same pattern works with real APIs like Google Calendar.

Step 1: Define the Calendar Functions

# Simple in-memory calendar storage
calendar_events = []

def add_calendar_event(title: str, date: str, time: str) -> str:
    """Add an event to the calendar.
    
    Args:
        title: The title or name of the event
        date: The date of the event (e.g., '2024-01-15')
        time: The time of the event (e.g., '14:30')
    
    Returns:
        Confirmation message
    """
    event = {
        "title": title,
        "date": date,
        "time": time
    }
    calendar_events.append(event)
    return f"Added '{title}' to calendar on {date} at {time}."

def list_calendar_events() -> str:
    """List all events currently on the calendar.
    
    Returns:
        A formatted list of all events
    """
    if not calendar_events:
        return "No events scheduled."
    
    event_list = []
    for i, event in enumerate(calendar_events, 1):
        event_list.append(f"{i}. {event['title']} - {event['date']} at {event['time']}")
    
    return "Calendar Events:\n" + "\n".join(event_list)

Step 2: Create Tool Descriptions

The agent needs to understand what each tool does. We provide this through docstrings and explicit descriptions:

calendar_tools = [
    {
        "name": "add_calendar_event",
        "description": "Add a new event to the calendar. Use this when the user wants to schedule something.",
        "parameters": {
            "title": "The name or title of the event",
            "date": "The date in YYYY-MM-DD format",
            "time": "The time in HH:MM format (24-hour)"
        }
    },
    {
        "name": "list_calendar_events",
        "description": "List all scheduled events. Use this when the user asks what's on their calendar.",
        "parameters": {}
    }
]
Pro Tip: Write your tool descriptions as if you're explaining them to someone who has never seen your code. The clearer the description, the better the agent will use the tool.

Building an Email Tool

Now let's add email capabilities. Again, we'll use a simulated email system to demonstrate the pattern.

# Simple email storage
sent_emails = []

def send_email(to: str, subject: str, body: str) -> str:
    """Send an email to a recipient.
    
    Args:
        to: The email address of the recipient
        subject: The subject line of the email
        body: The content of the email
    
    Returns:
        Confirmation that the email was sent
    """
    email = {
        "to": to,
        "subject": subject,
        "body": body
    }
    sent_emails.append(email)
    return f"Email sent to {to} with subject '{subject}'."

def check_inbox() -> str:
    """Check for new emails in the inbox.
    
    Returns:
        A summary of recent emails
    """
    # Simulated inbox
    return "You have 2 new emails: 1 from team@company.com, 1 from notifications@service.com"

Combining Tools in Your Agent

Here's how to combine both calendar and email tools in a single agent:

class SimpleAgent:
    def __init__(self):
        self.tools = {}
        self._register_default_tools()
    
    def _register_default_tools(self):
        """Register all available tools."""
        self.tools["add_calendar_event"] = add_calendar_event
        self.tools["list_calendar_events"] = list_calendar_events
        self.tools["send_email"] = send_email
        self.tools["check_inbox"] = check_inbox
    
    def execute_tool(self, tool_name: str, **kwargs):
        """Execute a tool by name with given parameters."""
        if tool_name not in self.tools:
            return f"Error: Tool '{tool_name}' not found."
        
        try:
            result = self.tools[tool_name](**kwargs)
            return result
        except Exception as e:
            return f"Error executing {tool_name}: {str(e)}"
    
    def list_available_tools(self):
        """List all tools the agent can use."""
        return list(self.tools.keys())

# Create an agent and test it
agent = SimpleAgent()

# Add a calendar event
print(agent.execute_tool("add_calendar_event", 
                          title="Team Meeting", 
                          date="2024-01-20", 
                          time="10:00"))

# Send an email
print(agent.execute_tool("send_email", 
                          to="team@company.com", 
                          subject="Meeting Reminder", 
                          body="Don't forget about our meeting tomorrow!"))

# List calendar events
print(agent.execute_tool("list_calendar_events"))

Tool Comparison: Calendar vs. Email

Feature Calendar Tools Email Tools
Primary Action Schedule and view events Send and receive messages
Typical Parameters title, date, time to, subject, body
Return Value Confirmation or event list Send confirmation or inbox summary
Real-World API Google Calendar API Gmail API / SMTP
Important: When working with real APIs (Google Calendar, Gmail), you'll need to handle authentication, rate limits, and error handling. Always test your tools thoroughly before relying on them in production.

Error Handling in Tools

Good tools handle errors gracefully. Here's an improved version of our calendar tool:

def add_calendar_event_safe(title: str, date: str, time: str) -> str:
    """Add an event to the calendar with error handling."""
    # Validate inputs
    if not title or not title.strip():
        return "Error: Event title cannot be empty."
    
    if not date or not date.strip():
        return "Error: Date is required."
    
    # Simple date format check
    if len(date) != 10 or date[4] != '-' or date[7] != '-':
        return "Error: Date must be in YYYY-MM-DD format."
    
    try:
        event = {
            "title": title.strip(),
            "date": date,
            "time": time
        }
        calendar_events.append(event)
        return f"✓ Added '{title}' to calendar on {date} at {time}."
    except Exception as e:
        return f"Error adding event: {str(e)}"

Practice Exercise

Exercise: Create a Reminder Tool

Create a new tool called set_reminder that:

  • Takes a message and minutes_from_now as parameters
  • Calculates the reminder time based on the current time
  • Returns a confirmation string with the reminder details

Then register it in the SimpleAgent class.

from datetime import datetime, timedelta

def set_reminder(message: str, minutes_from_now: int) -> str:
    """Set a reminder for a future time.
    
    Args:
        message: The reminder message
        minutes_from_now: How many minutes until the reminder
    
    Returns:
        Confirmation with reminder time
    """
    reminder_time = datetime.now() + timedelta(minutes=minutes_from_now)
    time_str = reminder_time.strftime("%H:%M")
    return f"⏰ Reminder set for {time_str}: {message}"

# Add to agent
agent.tools["set_reminder"] = set_reminder

# Test it
print(agent.execute_tool("set_reminder", 
                          message="Call the client", 
                          minutes_from_now=30))

Key Takeaways

  • Tools extend your agent's capabilities — Without tools, an agent can only generate text. With tools, it can take action.
  • Every tool needs a clear description — The agent relies on your description to know when and how to use each tool.
  • Error handling is essential — Always validate inputs and handle exceptions to make your tools robust.
  • The pattern is consistent — Define the function, describe it, register it. This same pattern works for any tool you create.
  • Start simple, then integrate real APIs — Use in-memory storage for testing, then swap in real services like Google Calendar or Gmail.
