Understanding Messages & Roles

Learn about understanding messages & roles.

What Are Messages?

In the world of AI agents, messages are the fundamental units of communication. Every interaction between a user, an AI agent, and external tools happens through structured messages. Think of messages like text messages in a conversation — each one carries specific content and comes from a specific sender.

When you interact with an AI agent, you're not just sending plain text. You're sending a structured message that includes:

  • Content — the actual text or data being communicated
  • Role — who is sending the message (user, assistant, system, or tool)
  • Metadata — additional information like timestamps, message IDs, etc.
# A simple message structure
message = {
    "role": "user",
    "content": "What's the weather like today?"
}

# A conversation is a list of messages
conversation = [
    {"role": "system", "content": "You are a helpful weather assistant."},
    {"role": "user", "content": "What's the weather like today?"},
    {"role": "assistant", "content": "It's sunny and 75°F in your area."}
]

Understanding Message Roles

Every message in an AI conversation has a role that defines its purpose and how the AI should treat it. There are four primary roles you need to understand:

The Four Core Roles

Role Purpose Who Sends It
system Sets the AI's behavior, personality, and rules Developer / Application
user Represents the human's input or request End User
assistant The AI's response or action AI Agent
tool Results from external tool calls (APIs, databases, etc.) External Systems

The System Role: Setting the Stage

The system message is the most powerful tool you have as a developer. It defines who the AI is, how it should behave, and what rules it must follow. The system message is typically the first message in any conversation and remains constant throughout.

# Example: Setting up a system message
system_message = {
    "role": "system",
    "content": (
        "You are a friendly coding tutor named CodeBuddy. "
        "You explain programming concepts in simple terms. "
        "Always provide code examples when helpful. "
        "If you don't know something, say so honestly."
    )
}

# The system message shapes every response the AI gives
conversation = [
    system_message,
    {"role": "user", "content": "What is a variable?"}
]
💡 Pro Tip: The system message is your primary tool for controlling AI behavior. Spend time crafting it carefully — it's like writing a job description for your AI agent!

The User Role: Human Input

The user role represents anything the human says or asks. This is the most straightforward role — it's simply the person interacting with the AI agent.

# User messages can be simple or complex
simple_message = {
    "role": "user",
    "content": "Hello!"
}

# Multi-part user messages (with images, files, etc.)
complex_message = {
    "role": "user",
    "content": [
        {"type": "text", "text": "What's in this image?"},
        {"type": "image_url", "image_url": {"url": "https://example.com/photo.jpg"}}
    ]
}

The Assistant Role: AI Responses

The assistant role is how the AI agent communicates back. This includes:

  • Text responses to user questions
  • Requests to call tools (before getting results)
  • Follow-up questions or clarifications
# A simple assistant response
assistant_message = {
    "role": "assistant",
    "content": "A variable is like a labeled box that stores data in programming."
}

# An assistant message requesting a tool call
tool_request = {
    "role": "assistant",
    "content": None,
    "tool_calls": [
        {
            "id": "call_123",
            "type": "function",
            "function": {
                "name": "get_weather",
                "arguments": '{"city": "New York"}'
            }
        }
    ]
}

The Tool Role: External Results

The tool role carries results from external systems back to the AI. When the AI requests information from an API, database, or other tool, the response comes back as a tool message.

# A tool message with results
tool_message = {
    "role": "tool",
    "tool_call_id": "call_123",
    "content": '{"temperature": 72, "condition": "sunny"}'
}

# The AI uses this tool result to formulate its next response
conversation = [
    {"role": "system", "content": "You are a weather assistant."},
    {"role": "user", "content": "What's the weather in New York?"},
    {   # Assistant requests tool
        "role": "assistant",
        "content": None,
        "tool_calls": [{"id": "call_123", "type": "function", "function": {"name": "get_weather", "arguments": '{"city": "New York"}'}}]
    },
    {   # Tool returns result
        "role": "tool",
        "tool_call_id": "call_123",
        "content": '{"temperature": 72, "condition": "sunny"}'
    },
    {   # Assistant responds with the data
        "role": "assistant",
        "content": "It's 72°F and sunny in New York today!"
    }
]
📚 Did You Know? The tool role is essential for building AI agents that can interact with the real world. Without it, AI would be limited to only what it learned during training!

How Messages Flow in a Conversation

Understanding the message flow is crucial for building effective AI agents. Here's how a typical conversation progresses:

  1. System message is sent first to set up the AI's behavior
  2. User message is sent with the human's request
  3. Assistant message is generated as the AI's response
  4. If the AI needs external data, it sends a tool call request
  5. Tool message returns the external data
  6. Assistant message provides the final response using the tool data
  7. The cycle repeats with new user messages
# Complete conversation flow example
conversation = [
    # 1. System sets the stage
    {
        "role": "system",
        "content": "You are a helpful assistant with access to a calculator."
    },
    # 2. User asks a question
    {
        "role": "user",
        "content": "What is 42 multiplied by 17?"
    },
    # 3. Assistant requests calculation via tool
    {
        "role": "assistant",
        "content": None,
        "tool_calls": [
            {
                "id": "calc_001",
                "type": "function",
                "function": {
                    "name": "multiply",
                    "arguments": '{"a": 42, "b": 17}'
                }
            }
        ]
    },
    # 4. Tool returns the result
    {
        "role": "tool",
        "tool_call_id": "calc_001",
        "content": "714"
    },
    # 5. Assistant provides final answer
    {
        "role": "assistant",
        "content": "42 multiplied by 17 equals 714."
    }
]

Building Messages in Python

Let's look at practical Python code for creating and managing messages in your AI agent.

Creating a Message Manager

class MessageManager:
    """Manages conversation messages for an AI agent."""
    
    def __init__(self, system_prompt: str):
        self.messages = [
            {"role": "system", "content": system_prompt}
        ]
    
    def add_user_message(self, content: str):
        """Add a user message to the conversation."""
        self.messages.append({
            "role": "user",
            "content": content
        })
    
    def add_assistant_message(self, content: str):
        """Add an assistant response to the conversation."""
        self.messages.append({
            "role": "assistant",
            "content": content
        })
    
    def add_tool_response(self, tool_call_id: str, content: str):
        """Add a tool response to the conversation."""
        self.messages.append({
            "role": "tool",
            "tool_call_id": tool_call_id,
            "content": content
        })
    
    def get_conversation(self) -> list:
        """Return the full conversation history."""
        return self.messages.copy()
    
    def get_last_n_messages(self, n: int) -> list:
        """Get the last n messages (useful for context limits)."""
        return self.messages[-n:]

Using the Message Manager

# Initialize with a system prompt
manager = MessageManager(
    system_prompt="You are a helpful math tutor for elementary students."
)

# Add user message
manager.add_user_message("What is 5 + 3?")

# Simulate assistant response
manager.add_assistant_message("5 + 3 = 8! Great question!")

# View the conversation
for msg in manager.get_conversation():
    print(f"[{msg['role']}]: {msg['content']}")

# Output:
# [system]: You are a helpful math tutor for elementary students.
# [user]: What is 5 + 3?
# [assistant]: 5 + 3 = 8! Great question!
⚠️ Important: Always keep the system message as the first message in your conversation. Removing or reordering it can cause unexpected AI behavior!

Common Message Patterns

Here are some common patterns you'll use when working with AI agent messages:

Pattern 1: Simple Q&A

# Basic question and answer
simple_qa = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "What is Python?"},
    {"role": "assistant", "content": "Python is a popular programming language..."}
]

Pattern 2: Multi-Turn Conversation

# Conversation with memory
multi_turn = [
    {"role": "system", "content": "You are a travel assistant."},
    {"role": "user", "content": "I want to visit Japan."},
    {"role": "assistant", "content": "Japan is wonderful! When are you planning to go?"},
    {"role": "user", "content": "Next spring, around April."},
    {"role": "assistant", "content": "April is perfect for cherry blossom season!..."}
]

Pattern 3: Tool-Using Agent

# Agent that uses external tools
tool_agent = [
    {"role": "system", "content": "You have access to weather and calendar tools."},
    {"role": "user", "content": "Do I need an umbrella for my meeting tomorrow?"},
    {
        "role": "assistant",
        "content": None,
        "tool_calls": [
            {"id": "w1", "type": "function", "function": {"name": "get_weather", "arguments": '{"date": "tomorrow"}'}},
            {"id": "c1", "type": "function", "function": {"name": "get_calendar", "arguments": '{"date": "tomorrow"}'}}
        ]
    },
    {"role": "tool", "tool_call_id": "w1", "content": '{"rain": true, "temp": 65}'},
    {"role": "tool", "tool_call_id": "c1", "content": '{"events": [{"time": "2pm", "location": "downtown"}]}'},
    {"role": "assistant", "content": "Yes, bring an umbrella! It will rain tomorrow and you have a 2pm meeting downtown."}
]
Exercise: Build a Message Sequence

Create a Python function called create_tutorial_messages that builds a message sequence for an AI coding tutor. The function should:

  1. Accept a student_question parameter
  2. Return a list of messages with:
    • A system message defining the AI as a "patient Python tutor for beginners"
    • A user message containing the student's question

Then, add a function add_tutorial_response that appends an assistant message to an existing conversation.

def create_tutorial_messages(student_question: str) -> list:
    """Create initial message sequence for a coding tutor."""
    return [
        {
            "role": "system",
            "content": (
                "You are a patient Python tutor for beginners. "
                "Explain concepts clearly with simple examples. "
                "Encourage students and celebrate their progress."
            )
        },
        {
            "role": "user",
            "content": student_question
        }
    ]


def add_tutorial_response(conversation: list, response: str) -> list:
    """Add an assistant response to the tutorial conversation."""
    conversation.append({
        "role": "assistant",
        "content": response
    })
    return conversation


# Example usage:
messages = create_tutorial_messages("How do I create a list in Python?")
print(messages)

# After getting a response from the AI:
messages = add_tutorial_response(
    messages,
    "You create a list using square brackets. For example: my_list = [1, 2, 3]"
)
print(messages)

Key Takeaways

  • Messages are the building blocks of AI agent conversations, containing content, role, and metadata.
  • There are four core roles: system (sets behavior), user (human input), assistant (AI response), and tool (external results).
  • The system message is the most powerful tool for controlling AI behavior — craft it carefully!
  • Messages flow in a specific order: system → user → assistant → (optionally) tool → assistant.
  • Use a Message Manager class to organize and maintain conversation history cleanly.
  • Common patterns include simple Q&A, multi-turn conversations, and tool-using agent flows.
  • Always keep the system message first in your conversation list.
