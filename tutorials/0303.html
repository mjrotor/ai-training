Few-Shot Prompting

Learn about few-shot prompting.

What Is Few-Shot Prompting?

In the previous lessons, we learned about zero-shot prompting—asking an AI model to perform a task with no examples. While powerful, zero-shot prompting doesn't always give us the precise output we want, especially when we need a specific format or style.

Few-shot prompting is a technique where we provide the AI model with a few examples of the task we want it to perform, along with the desired output for each example. By showing the pattern, we help the model understand exactly what we're looking for.

💡 Why "Few-Shot"? The term comes from machine learning, where "shots" refers to examples. "Zero-shot" means no examples, "one-shot" means one example, and "few-shot" means a small number of examples (typically 2-5).

How Few-Shot Prompting Works

The basic structure of a few-shot prompt looks like this:

  1. Task Description - What you want the AI to do
  2. Examples - Input/output pairs showing the pattern
  3. New Input - The actual input you want processed
  4. Expected Output - The AI generates this based on the pattern
Task: Classify the sentiment of each sentence as positive, negative, or neutral.

Examples:
1. "I love this product!" → positive
2. "This is terrible." → negative
3. "It's okay, nothing special." → neutral

Now classify: "The service was excellent and fast!"
Expected output: positive

Implementing Few-Shot Prompting with Python

Let's see how to implement few-shot prompting using Python. We'll build a sentiment analysis classifier.

import requests

def few_shot_sentiment(text):
    """
    Classify sentiment using few-shot prompting.
    """
    # Define our examples
    examples = [
        ('I love this product!', 'positive'),
        ('This is terrible.', 'negative'),
        ("It's okay, nothing special.", 'neutral'),
        ('Amazing quality, highly recommend!', 'positive'),
        ('Worst purchase ever.', 'negative')
    ]
    
    # Build the prompt with examples
    prompt = "Classify the sentiment of each sentence as positive, negative, or neutral.\n\n"
    
    # Add examples
    for i, (example_text, sentiment) in enumerate(examples, 1):
        prompt += f'{i}. "{example_text}" → {sentiment}\n'
    
    # Add the new text to classify
    prompt += f'\nNow classify: "{text}"\nSentiment:'
    
    # Make API call
    response = requests.post(
        'YOUR_API_ENDPOINT',
        json={
            'prompt': prompt,
            'max_tokens': 10,
            'temperature': 0.1
        }
    )
    
    return response.json()['choices'][0]['text'].strip()

# Test our function
test_texts = [
    "The movie was fantastic!",
    "I'm disappointed with the quality.",
    "It was an average experience."
]

for text in test_texts:
    sentiment = few_shot_sentiment(text)
    print(f'"{text}" → {sentiment}')

Best Practices for Few-Shot Prompting

Here are key principles to follow when using few-shot prompting:

1. Choose Diverse Examples

Your examples should cover different cases and edge conditions. This helps the model generalize better.

# Good: Diverse examples
examples = [
    ("The weather is beautiful today", "positive"),  # Simple positive
    ("I hate waiting in long lines", "negative"),   # Simple negative
    ("The meeting is at 3 PM", "neutral"),          # Factual/neutral
    ("Not bad at all!", "positive"),                # Idiomatic
    ("Could be worse", "negative")               # Subtle negative
]

# Bad: All examples are too similar
examples = [
    ("I love it", "positive"),
    ("I love this", "positive"),
    ("I love that", "positive")
]

2. Maintain Consistent Format

The format of your examples should match the format you want for the output.

# Consistent format
examples = [
    ('"Amazing service!" → POSITIVE'),
    ('"Terrible experience" → NEGATIVE'),
    ('"It was fine" → NEUTRAL')
]

# Inconsistent format - avoid this!
examples = [
    ('"Amazing service!" → positive'),
    ('"Terrible experience" → Negative'),
    ('"It was fine" → NEUTRAL')
]

3. Use Clear Delimiters

Clearly separate examples from the actual input using delimiters.

prompt = """Classify the following reviews as positive or negative.

Examples:
---
Review: "Great product!"
Sentiment: positive
---
Review: "Waste of money"
Sentiment: negative
---

Now classify:
Review: "Exceeded my expectations"
Sentiment:"""

Comparing Prompting Techniques

Technique Examples Provided Best For Token Usage
Zero-Shot 0 Simple, well-defined tasks Low
One-Shot 1 Format demonstration Low-Medium
Few-Shot 2-5 Pattern learning, style matching Medium

Advanced Example: Email Classification

Let's build a more complex example that classifies emails into categories.

def classify_email(email_text):
    """
    Classify emails into categories using few-shot prompting.
    """
    examples = [
        {
            'email': 'Hi team, please review the attached budget proposal.',
            'category': 'work',
            'priority': 'normal'
        },
        {
            'email': 'URGENT: Server is down! Need immediate assistance.',
            'category': 'work',
            'priority': 'high'
        },
        {
            'email': 'Your Amazon order has shipped!',
            'category': 'personal',
            'priority': 'low'
        },
        {
            'email': 'Meeting reminder: Project review at 2 PM today',
            'category': 'work',
            'priority': 'normal'
        }
    ]
    
    # Build prompt
    prompt = "Classify the following emails by category and priority.\n"
    prompt += "Categories: work, personal, spam\n"
    prompt += "Priorities: high, normal, low\n\n"
    
    for i, ex in enumerate(examples, 1):
        prompt += f"Email {i}: \"{ex['email']}\"\n"
        prompt += f"Category: {ex['category']}, Priority: {ex['priority']}\n\n"
    
    prompt += f"Email to classify: \"{email_text}\"\n"
    prompt += "Category: , Priority: "
    
    # Call API
    response = requests.post(
        'YOUR_API_ENDPOINT',
        json={'prompt': prompt, 'max_tokens': 20}
    )
    
    return response.json()['choices'][0]['text'].strip()

# Test
test_emails = [
    "Flash sale! 50% off everything - limited time!",
    "Can we schedule a call to discuss the proposal?",
    "Your subscription is about to expire"
]

for email in test_emails:
    result = classify_email(email)
    print(f'Email: {email[:40]}...')
    print(f'Result: {result}\n')
💡 Pro Tip: When building few-shot prompts, start with 2-3 examples and add more only if the model isn't performing well. More examples use more tokens and increase costs without always improving results.

Common Pitfalls to Avoid

⚠️ Watch Out For:
  • Overfitting to examples - Don't make examples too specific; the model needs to generalize
  • Inconsistent formatting - Keep your example format exactly the same
  • Too many examples - More isn't always better; 3-5 is usually sufficient
  • Biased examples - Ensure your examples represent diverse cases

When to Use Few-Shot vs. Zero-Shot

Use this decision framework:

  • Use Zero-Shot when: The task is simple, the model already knows the domain, or you're prototyping quickly
  • Use Few-Shot when: You need specific output formats, the task is nuanced, or zero-shot results are inconsistent

Key Takeaways

  • Few-shot prompting provides examples to help AI models understand the desired output pattern
  • Typically 2-5 examples are sufficient—more isn't always better
  • Examples should be diverse, consistent in format, and clearly separated from the actual input
  • Few-shot prompting is especially useful for format-specific tasks and nuanced classifications
  • Always test your prompts with edge cases to ensure the model generalizes well
