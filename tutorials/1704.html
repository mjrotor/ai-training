Synthesis & Summarization

Learn about synthesis & summarization.

What Is Synthesis & Summarization?

As AI agents become more capable, one of their most valuable skills is the ability to take large amounts of information and distill it into something concise and useful. Synthesis means combining multiple sources of information to create a unified understanding, while summarization means condensing a single piece of content into its most important points. Together, these capabilities allow agents to process documents, research papers, meeting transcripts, and more — turning raw data into actionable insights.

In this lesson, you'll learn how to build agents that can summarize text, synthesize information from multiple sources, and present results in structured formats.

Text Summarization Techniques

There are two main approaches to text summarization:

  • Extractive summarization: Selects the most important sentences or phrases directly from the source text.
  • Abstractive summarization: Generates new sentences that capture the meaning of the source, often using language models.
💡 Did you know? Extractive summarization is faster and more faithful to the original text, while abstractive summarization can produce more natural-sounding summaries but may introduce inaccuracies.

Extractive Summarization with Python

Here's a simple example using the sumy library to perform extractive summarization:

from sumy.parsers.plaintext import PlaintextParser
from sumy.nlp.tokenizers import Tokenizer
from sumy.summarizers.lsa import LsaSummarizer

text = """
Artificial intelligence (AI) is transforming industries across the globe. 
From healthcare to finance, AI systems are being deployed to automate tasks, 
analyze data, and make predictions. Machine learning, a subset of AI, 
enables computers to learn from data without being explicitly programmed. 
Deep learning, in turn, uses neural networks with many layers to model 
complex patterns in data. These technologies are driving innovation in 
areas such as natural language processing, computer vision, and robotics.
"""

parser = PlaintextParser.from_string(text, Tokenizer("english"))
summarizer = LsaSummarizer()
summary = summarizer(parser.document, sentences_count=2)

for sentence in summary:
    print(sentence)

Abstractive Summarization with Transformers

For more advanced summarization, you can use a pre-trained transformer model:

from transformers import pipeline

summarizer = pipeline("summarization", model="facebook/bart-large-cnn")

article = """
The James Webb Space Telescope (JWST) has captured unprecedented images 
of distant galaxies, revealing details about the early universe that were 
previously invisible to astronomers. Launched in December 2021, JWST 
uses infrared sensors to peer through cosmic dust and observe stars 
forming billions of light-years away. Scientists say these observations 
could reshape our understanding of how galaxies formed and evolved.
"""

result = summarizer(article, max_length=50, min_length=10, do_sample=False)
print(result[0]['summary_text'])
✅ Pro tip: When using abstractive summarization, always verify the output against the source text. Language models can sometimes "hallucinate" facts that weren't in the original content.

Synthesis: Combining Multiple Sources

Summarization works on a single document, but synthesis goes further — it combines information from multiple sources to create a coherent overview. This is especially useful when you need to compare viewpoints, aggregate research findings, or build a knowledge base from diverse inputs.

Building a Multi-Source Synthesis Agent

Here's an example of an agent that reads multiple text files and synthesizes their content:

import os
from transformers import pipeline

class SynthesisAgent:
    def __init__(self):
        self.summarizer = pipeline("summarization", model="facebook/bart-large-cnn")
    
    def read_sources(self, file_paths):
        """Read multiple source files and return their contents."""
        sources = {}
        for path in file_paths:
            with open(path, 'r') as f:
                sources[os.path.basename(path)] = f.read()
        return sources
    
    def summarize_sources(self, sources):
        """Summarize each source individually."""
        summaries = {}
        for name, content in sources.items():
            summary = self.summarizer(content, max_length=60, min_length=15)
            summaries[name] = summary[0]['summary_text']
        return summaries
    
    def synthesize(self, summaries):
        """Combine summaries into a single synthesis."""
        combined = " ".join(summaries.values())
        final = self.summarizer(combined, max_length=80, min_length=20)
        return final[0]['summary_text']

# Usage
agent = SynthesisAgent()
sources = agent.read_sources(["doc1.txt", "doc2.txt", "doc3.txt"])
summaries = agent.summarize_sources(sources)
result = agent.synthesize(summaries)
print("Synthesis:", result)

Comparison: Summarization vs. Synthesis

Feature Summarization Synthesis
Input Single document Multiple documents
Goal Condense content Unify and compare content
Complexity Lower Higher
Use Case Quick overviews, note-taking Research, reports, decision-making
Output Shortened version of one source New narrative combining multiple sources

Structured Output Formats

When building agents that summarize or synthesize, it's often helpful to return results in structured formats like JSON or Markdown. This makes the output easier to consume by other systems or display in user interfaces.

import json

def summarize_to_json(text, summarizer_pipeline):
    """Return a summary in structured JSON format."""
    summary = summarizer_pipeline(text, max_length=50, min_length=10)
    result = {
        "original_length": len(text.split()),
        "summary_length": len(summary[0]['summary_text'].split()),
        "summary": summary[0]['summary_text'],
        "compression_ratio": round(
            len(summary[0]['summary_text'].split()) / len(text.split()), 2
        )
    }
    return json.dumps(result, indent=2)

# Example usage
from transformers import pipeline
summarizer = pipeline("summarization", model="facebook/bart-large-cnn")

text = "Your long article text goes here..."
output = summarize_to_json(text, summarizer)
print(output)
⚠️ Watch out! Always set max_length and min_length parameters when using summarization pipelines. Without them, the model may produce summaries that are too long or too short for your needs.

Handling Long Documents

Most language models have a maximum token limit (e.g., 1024 or 4096 tokens). When summarizing long documents, you need to split the text into chunks, summarize each chunk, and then combine the results.

def chunk_text(text, max_tokens=900):
    """Split text into chunks of approximately max_tokens words."""
    words = text.split()
    chunks = []
    for i in range(0, len(words), max_tokens):
        chunks.append(" ".join(words[i:i + max_tokens]))
    return chunks

def summarize_long_document(text, summarizer_pipeline):
    """Summarize a long document by chunking and combining."""
    chunks = chunk_text(text)
    chunk_summaries = []
    
    for chunk in chunks:
        summary = summarizer_pipeline(chunk, max_length=40, min_length=10)
        chunk_summaries.append(summary[0]['summary_text'])
    
    # Combine chunk summaries into a final summary
    combined = " ".join(chunk_summaries)
    final = summarizer_pipeline(combined, max_length=60, min_length=15)
    return final[0]['summary_text']

Exercise: Build a Bullet-Point Summarizer

Write a Python function called summarize_to_bullets that takes a string of text and returns a summary formatted as a list of bullet points. The function should:

  1. Accept a text string and an optional num_bullets parameter (default: 3).
  2. Use a summarization pipeline to generate a summary.
  3. Split the summary into sentences.
  4. Return the first num_bullets sentences as a list of strings, each prefixed with "• ".

Test your function with a paragraph of your choice.

from transformers import pipeline

def summarize_to_bullets(text, num_bullets=3):
    summarizer = pipeline("summarization", model="facebook/bart-large-cnn")
    result = summarizer(text, max_length=80, min_length=20)
    summary_text = result[0]['summary_text']
    
    # Split into sentences (simple split on periods)
    sentences = [s.strip() for s in summary_text.split('.') if s.strip()]
    
    # Take the first num_bullets sentences
    bullets = sentences[:num_bullets]
    
    # Prefix each with a bullet point
    return [f"• {sentence}." for sentence in bullets]

Key Takeaways

  • Summarization condenses a single document into its most important points, while synthesis combines multiple sources into a unified understanding.
  • Extractive summarization selects existing sentences from the source; abstractive summarization generates new text using language models.
  • Use the transformers library and pre-trained models like bart-large-cnn for high-quality abstractive summarization.
  • Always set max_length and min_length parameters to control summary length.
  • For long documents, split text into chunks, summarize each chunk, and combine the results.
  • Return summaries in structured formats (JSON, bullet points, Markdown) for easier integration with other systems.
  • Verify abstractive summaries against source text to catch potential hallucinations.
