Understanding Temperature, Tokens & Parameters

When you interact with an AI agent, you're not just sending a message into a black box. Behind the scenes, several key settings shape how the AI responds. In this lesson, we'll explore three fundamental concepts that control the behavior of AI agents: temperature, tokens, and parameters. Understanding these will help you get better, more predictable results from your AI interactions.

What Are Tokens?

Before we dive into temperature and other parameters, we need to understand tokens — the basic units of text that AI models process.

Tokens: The Building Blocks of AI Text

AI models don't read text the way humans do. Instead, they break down text into smaller pieces called tokens. A token can be:

  • A whole word (e.g., "hello")
  • A part of a word (e.g., "un" + "break" + "able")
  • A punctuation mark (e.g., "." or "!")
  • A space or special character

As a rough rule of thumb, 1 token ≈ 4 characters in English, or about 0.75 words. So the sentence "Hello, world!" might be broken into 4 tokens: ["Hello", ",", " world", "!"].

💡 Did you know? Different AI models use different tokenizers. The same sentence might be split into a different number of tokens depending on which model you're using. This is why token counts can vary between services.

Why Tokens Matter

Tokens are important for two main reasons:

  1. Cost: Most AI services charge based on the number of tokens you send and receive. More tokens = higher cost.
  2. Limits: Every AI model has a context window — a maximum number of tokens it can process in a single request. If your input plus the expected output exceeds this limit, the request will fail or the response will be cut off.

Counting Tokens in Python

Let's see how to count tokens using Python. Many AI libraries include built-in tokenizers, but we can also use the tiktoken library (used by OpenAI models) to count tokens directly.

import tiktoken

# Load the tokenizer for a specific model
enc = tiktoken.encoding_for_model("gpt-4")

# A sample text
text = "Hello, world! This is a tutorial about AI agents."

# Encode the text into tokens
tokens = enc.encode(text)

# Count the tokens
token_count = len(tokens)
print(f"Text: '{text}'")
print(f"Number of tokens: {token_count}")
print(f"Tokens: {tokens}")

# Decode back to see what each token represents
for token_id in tokens:
    token_text = enc.decode([token_id])
    print(f"  Token ID {token_id} → '{token_text}'")

Running this code will show you exactly how the text is broken down into individual tokens and how many there are.

🔧 Pro Tip: When building AI applications, always estimate your token usage before making API calls. This helps you stay within budget and avoid hitting context window limits unexpectedly.

What Is Temperature?

Temperature is one of the most important parameters you can control when working with AI models. It determines how creative or predictable the AI's responses will be.

How Temperature Works

When an AI model generates text, it doesn't just pick the single most likely next word. Instead, it assigns a probability to every possible next word. Temperature controls how the model uses these probabilities:

  • Low temperature (0.0 – 0.3): The model strongly favors the most likely words. Responses are more deterministic, focused, and predictable. Great for factual answers, code generation, and structured tasks.
  • Medium temperature (0.4 – 0.7): A balanced mix of likely and less likely words. Responses are somewhat creative but still coherent. Good for general conversation and explanations.
  • High temperature (0.8 – 2.0): The model is more willing to pick less likely words. Responses are more creative, diverse, and sometimes surprising. Useful for brainstorming, storytelling, and idea generation.
⚠️ Warning: Setting temperature to 0 doesn't guarantee the exact same output every time in all implementations. Some models may still have slight variations due to internal processing. For truly deterministic results, you may also need to set a fixed seed value.

Temperature in Practice

Here's how you set the temperature parameter when making an API call:

from openai import OpenAI

client = OpenAI()

# Low temperature — focused and deterministic
response_focused = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "Explain what a variable is in Python."}
    ],
    temperature=0.1
)
print("Low temperature response:")
print(response_focused.choices[0].message.content)

# High temperature — creative and varied
response_creative = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "Explain what a variable is in Python."}
    ],
    temperature=1.5
)
print("\nHigh temperature response:")
print(response_creative.choices[0].message.content)

Try running this code and compare the two responses. You'll notice the low-temperature version is more straightforward and factual, while the high-temperature version might use more varied language, metaphors, or examples.

Temperature Comparison Table

Temperature Range Behavior Best Used For Example Use Case
0.0 – 0.3 Deterministic, focused Factual Q&A, code, data extraction "Write a function that sorts a list"
0.4 – 0.7 Balanced General conversation, explanations "Explain how photosynthesis works"
0.8 – 1.2 Creative, diverse Brainstorming, writing, ideation "Give me 10 creative names for a coffee shop"

Other Important Parameters

Temperature isn't the only parameter that shapes AI behavior. Let's look at several other key parameters you'll encounter when working with AI agents.

max_tokens

The max_tokens parameter sets the maximum length of the AI's response. This is crucial for controlling costs and preventing overly long outputs.

response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "Write a short summary of Python."}
    ],
    max_tokens=50  # Limit response to approximately 50 tokens
)
print(response.choices[0].message.content)
💡 Note: max_tokens limits the output only. Your input tokens are counted separately. The total of input + output tokens must still fit within the model's context window.

top_p (Nucleus Sampling)

top_p is an alternative to temperature for controlling randomness. Instead of adjusting the probability distribution, it tells the model to only consider the top words whose cumulative probability adds up to p.

  • top_p = 0.1: Only consider the top 10% most likely words (very focused)
  • top_p = 0.9: Consider a broad range of words (more diverse)
  • top_p = 1.0: Consider all words (maximum diversity)
response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "Suggest a fun weekend activity."}
    ],
    top_p=0.3  # Only pick from the most likely options
)
print(response.choices[0].message.content)
🔧 Pro Tip: It's generally recommended to adjust either temperature or top_p, but not both at the same time. Adjusting both can lead to unpredictable behavior. Pick one and stick with it.

frequency_penalty and presence_penalty

These two parameters help control repetition in AI responses:

  • frequency_penalty (range: -2.0 to 2.0): Penalizes words that have already appeared frequently in the text. Higher values reduce repeated phrases and words.
  • presence_penalty (range: -2.0 to 2.0): Penalizes words that have appeared at all in the text. Higher values encourage the model to introduce new topics and ideas.
response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "Write a paragraph about the benefits of exercise."}
    ],
    frequency_penalty=1.0,   # Reduce repeated words
    presence_penalty=0.5     # Encourage new ideas
)
print(response.choices[0].message.content)

stop

The stop parameter lets you define stop sequences — strings that, when generated, cause the AI to stop producing text. This is useful for controlling the format of responses.

response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "List three programming languages."}
    ],
    stop=["4.", "\n\n"]  # Stop if the model tries to add a 4th item
)
print(response.choices[0].message.content)

Putting It All Together

Here's a complete example that combines all the parameters we've discussed:

from openai import OpenAI

client = OpenAI()

def ask_ai(question, temperature=0.7, max_tokens=200, top_p=1.0,
           frequency_penalty=0.0, presence_penalty=0.0):
    """
    Ask the AI a question with full control over generation parameters.
    """
    response = client.chat.completions.create(
        model="gpt-4",
        messages=[
            {"role": "system", "content": "You are a helpful programming tutor."},
            {"role": "user", "content": question}
        ],
        temperature=temperature,
        max_tokens=max_tokens,
        top_p=top_p,
        frequency_penalty=frequency_penalty,
        presence_penalty=presence_penalty
    )

    # Count tokens used
    usage = response.usage
    print(f"--- Token Usage ---")
    print(f"Prompt tokens: {usage.prompt_tokens}")
    print(f"Completion tokens: {usage.completion_tokens}")
    print(f"Total tokens: {usage.total_tokens}")
    print(f"--- Response ---")

    return response.choices[0].message.content

# Example: Factual question with low temperature
answer = ask_ai(
    "What is the difference between a list and a tuple in Python?",
    temperature=0.2,
    max_tokens=150
)
print(answer)

Exercise

🧪 Exercise: Experiment with Temperature

Write a Python script that asks the AI the same question three times with three different temperature settings (0.1, 0.7, and 1.5). Print each response side by side and observe how the tone, word choice, and creativity change.

Your question: "Describe a sunset over the ocean."

Requirements:

  • Use a loop to iterate over the three temperature values
  • Print the temperature value before each response
  • Set max_tokens to 100 to keep responses manageable
  • Add a blank line between responses for readability
from openai import OpenAI

client = OpenAI()

question = "Describe a sunset over the ocean."
temperatures = [0.1, 0.7, 1.5]

for temp in temperatures:
    print(f"=== Temperature: {temp} ===")
    response = client.chat.completions.create(
        model="gpt-4",
        messages=[
            {"role": "user", "content": question}
        ],
        temperature=temp,
        max_tokens=100
    )
    print(response.choices[0].message.content)
    print()  # Blank line for readability

When you run this, you should notice that the 0.1 response is concise and factual, the 0.7 response is balanced and descriptive, and the 1.5 response is more poetic and imaginative.

Key Takeaways

  • Tokens are the basic units of text that AI models process. Understanding tokens helps you manage costs and stay within model limits.
  • Temperature controls the randomness of AI output. Use low values (0.0–0.3) for factual tasks and high values (0.8–1.5) for creative tasks.
  • max_tokens limits the length of the AI's response, helping you control costs and output size.
  • top_p is an alternative to temperature for controlling output diversity through nucleus sampling.
  • frequency_penalty and presence_penalty help reduce repetition and encourage variety in responses.
  • stop sequences let you define where the AI should stop generating text.
  • Adjust either temperature or top_p — avoid changing both simultaneously for predictable results.
  • Always monitor your token usage to stay within budget and context window limits.
