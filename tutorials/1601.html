Understanding Communication Patterns in AI Agents

As AI agents grow more complex, they rarely work in isolation. Real-world applications often require multiple agents to collaborate, share information, and coordinate their actions. In this lesson, we'll explore the fundamental communication patterns that enable agents to work together effectively.

Why Communication Matters

Think of a team of specialists working on a complex project. A doctor, a lawyer, and an engineer each bring unique expertise. They need to communicate clearly to solve problems that span their individual domains. Similarly, AI agents need structured ways to:

  • Share context and intermediate results
  • Coordinate task execution
  • Resolve conflicts or ambiguities
  • Build upon each other's work
Key Insight: The way agents communicate directly impacts the quality and efficiency of their collective output. Poor communication leads to duplicated work, conflicting results, and wasted resources.

Core Communication Patterns

There are several established patterns for agent communication. Let's examine the most common ones:

1. Request-Response Pattern

The simplest pattern where one agent sends a request and waits for a response. This is synchronous and blocking.

import asyncio
from dataclasses import dataclass
from typing import Any

@dataclass
class Message:
    sender: str
    content: str
    message_type: str = "request"

class SimpleAgent:
    def __init__(self, name: str):
        self.name = name
        self.inbox = []
    
    async def send_request(self, recipient: 'SimpleAgent', content: str) -> str:
        """Send a request and wait for response"""
        request = Message(sender=self.name, content=content)
        print(f"[{self.name}] Sending request to {recipient.name}: {content}")
        
        # Simulate processing delay
        await asyncio.sleep(0.5)
        
        response = await recipient.handle_request(request)
        return response
    
    async def handle_request(self, message: Message) -> str:
        """Handle incoming request and return response"""
        print(f"[{self.name}] Received request from {message.sender}: {message.content}")
        
        # Process the request
        response = f"Processed: {message.content}"
        return response

# Usage example
async def main():
    agent_a = SimpleAgent("Agent A")
    agent_b = SimpleAgent("Agent B")
    
    result = await agent_a.send_request(agent_b, "Analyze this data")
    print(f"Final result: {result}")

# Run the example
# asyncio.run(main())

2. Publish-Subscribe Pattern

Agents publish messages to topics, and other agents subscribe to topics they're interested in. This decouples senders from receivers.

from collections import defaultdict
from typing import Callable, List

class PubSubSystem:
    def __init__(self):
        self.subscribers = defaultdict(list)
        self.message_history = []
    
    def subscribe(self, topic: str, callback: Callable):
        """Subscribe to a topic"""
        self.subscribers[topic].append(callback)
        print(f"New subscriber added to topic: {topic}")
    
    def publish(self, topic: str, message: Any, sender: str):
        """Publish a message to a topic"""
        msg_data = {
            'topic': topic,
            'message': message,
            'sender': sender
        }
        self.message_history.append(msg_data)
        
        # Notify all subscribers
        for callback in self.subscribers[topic]:
            callback(msg_data)

# Example usage
pubsub = PubSubSystem()

def data_processor(msg):
    print(f"Data Processor received: {msg['message']}")

def logger(msg):
    print(f"Logger recorded: {msg['sender']} -> {msg['topic']}")

# Subscribe agents to topics
pubsub.subscribe("data_updates", data_processor)
pubsub.subscribe("data_updates", logger)
pubsub.subscribe("alerts", logger)

# Publish messages
pubsub.publish("data_updates", {"value": 42}, "Sensor Agent")
pubsub.publish("alerts", "High temperature detected", "Monitor Agent")

3. Pipeline Pattern

Data flows through a sequence of agents, each performing a specific transformation. This is ideal for data processing workflows.

from typing import Any, List
import time

class PipelineAgent:
    def __init__(self, name: str, transform_fn):
        self.name = name
        self.transform_fn = transform_fn
        self.next_agent = None
    
    def set_next(self, agent: 'PipelineAgent'):
        """Set the next agent in the pipeline"""
        self.next_agent = agent
        return agent  # Return for chaining
    
    async def process(self, data: Any) -> Any:
        """Process data and pass to next agent"""
        print(f"[{self.name}] Processing: {data}")
        
        # Apply transformation
        result = self.transform_fn(data)
        print(f"[{self.name}] Output: {result}")
        
        # Pass to next agent if exists
        if self.next_agent:
            return await self.next_agent.process(result)
        return result

# Create pipeline agents
validator = PipelineAgent("Validator", lambda x: x if x > 0 else 0)
normalizer = PipelineAgent("Normalizer", lambda x: x / 100)
analyzer = PipelineAgent("Analyzer", lambda x: {"value": x, "status": "analyzed"})

# Chain them together
validator.set_next(normalizer).set_next(analyzer)

# Output: {'value': 0.75, 'status': 'analyzed'}

Comparing Communication Patterns

Pattern Best For Complexity Coupling
Request-Response Simple queries, immediate answers Low Tight
Publish-Subscribe Event-driven systems, notifications Medium Loose
Pipeline Data processing, sequential tasks Medium Medium
Blackboard Complex problem-solving, shared state High Loose
Pro Tip: Start with the simplest pattern that meets your needs. You can always refactor to a more complex pattern as your system grows.

Implementing a Blackboard Pattern

The blackboard pattern is powerful for complex problem-solving where multiple agents contribute to a shared solution space.

from typing import Dict, List, Any
from dataclasses import dataclass, field
from datetime import datetime

@dataclass
class BlackboardEntry:
    key: str
    value: Any
    contributor: str
    timestamp: datetime = field(default_factory=datetime.now)

class Blackboard:
    def __init__(self):
        self.entries: Dict[str, BlackboardEntry] = {}
        self.subscribers: List[Callable] = []
    
    def write(self, key: str, value: Any, contributor: str):
        """Write data to the blackboard"""
        entry = BlackboardEntry(key=key, value=value, contributor=contributor)
        self.entries[key] = entry
        print(f"Blackboard updated: {key} = {value} (by {contributor})")
        
        # Notify subscribers
        for callback in self.subscribers:
            callback(key, entry)
    
    def read(self, key: str) -> Any:
        """Read data from the blackboard"""
        entry = self.entries.get(key)
        return entry.value if entry else None
    
    def get_all(self) -> Dict[str, Any]:
        """Get all entries"""
        return {k: v.value for k, v in self.entries.items()}

class BlackboardAgent:
    def __init__(self, name: str, blackboard: Blackboard):
        self.name = name
        self.blackboard = blackboard
    
    def contribute(self, key: str, value: Any):
        """Contribute knowledge to the blackboard"""
        self.blackboard.write(key, value, self.name)
    
    def check_blackboard(self, key: str) -> Any:
        """Check for specific information"""
        return self.blackboard.read(key)

# Example: Problem-solving with multiple agents
blackboard = Blackboard()

researcher = BlackboardAgent("Researcher", blackboard)
analyst = BlackboardAgent("Analyst", blackboard)
synthesizer = BlackboardAgent("Synthesizer", blackboard)

# Agents contribute their findings
researcher.contribute("raw_data", [10, 20, 30, 40, 50])
analyst.contribute("statistics", {"mean": 30, "std": 15.8})
synthesizer.contribute("conclusion", "Data shows positive trend")

# Any agent can access the shared knowledge
print(blackboard.get_all())
Warning: The blackboard pattern can become a bottleneck if not managed properly. Consider implementing access controls and versioning for production systems.

Handling Asynchronous Communication

In real-world systems, agents often operate asynchronously. Here's how to handle this effectively:

import asyncio
from typing import Dict, List
from collections import deque

class AsyncMessageBus:
    def __init__(self):
        self.queues: Dict[str, asyncio.Queue] = {}
        self.message_log = []
    
    def register_agent(self, agent_name: str):
        """Register an agent with its own message queue"""
        self.queues[agent_name] = asyncio.Queue()
        print(f"Agent registered: {agent_name}")
    
    async def send(self, recipient: str, message: Dict):
        """Send a message to a specific agent"""
        if recipient in self.queues:
            await self.queues[recipient].put(message)
            self.message_log.append({
                'to': recipient,
                'message': message,
                'timestamp': asyncio.get_event_loop().time()
            })
    
    async def receive(self, agent_name: str) -> Dict:
        """Receive a message (blocks until message available)"""
        if agent_name in self.queues:
            return await self.queues[agent_name].get()
        return None
    
    async def broadcast(self, message: Dict, exclude: str = None):
        """Broadcast message to all agents"""
        for agent_name in self.queues:
            if agent_name != exclude:
                await self.send(agent_name, message)

# Example usage
async def agent_worker(name: str, bus: AsyncMessageBus):
    """Simulate an agent processing messages"""
    while True:
        message = await bus.receive(name)
        if message is None:
            break
        
        print(f"[{name}] Processing: {message}")
        await asyncio.sleep(0.1)  # Simulate work
        
        # Send response
        if 'reply_to' in message:
            await bus.send(message['reply_to'], {
                'from': name,
                'response': f"Processed: {message.get('data', '')}"
            })

# Setup and run
async def main():
    bus = AsyncMessageBus()
    bus.register_agent("Agent1")
    bus.register_agent("Agent2")
    
    # Start agent workers
    workers = [
        asyncio.create_task(agent_worker("Agent1", bus)),
        asyncio.create_task(agent_worker("Agent2", bus))
    ]
    
    # Send initial message
    await bus.send("Agent1", {
        'data': 'Hello from main',
        'reply_to': 'Agent2'
    })
    
    await asyncio.sleep(1)
    
    # Cleanup
    for worker in workers:
        worker.cancel()

# asyncio.run(main())

Error Handling in Agent Communication

Robust communication requires proper error handling. Here are key strategies:

  1. Timeouts: Always set timeouts for requests to prevent indefinite waiting
  2. Retry Logic: Implement exponential backoff for transient failures
  3. Circuit Breakers: Stop sending requests to failing agents temporarily
  4. Dead Letter Queues: Store failed messages for later analysis
import asyncio
from typing import Optional
from enum import Enum

class CircuitState(Enum):
    CLOSED = "closed"
    OPEN = "open"
    HALF_OPEN = "half_open"

class CircuitBreaker:
    def __init__(self, failure_threshold: int = 3, recovery_timeout: float = 5.0):
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.state = CircuitState.CLOSED
        self.failure_count = 0
        self.last_failure_time = 0
    
    async def call(self, func, *args, **kwargs):
        """Execute function with circuit breaker protection"""
        if self.state == CircuitState.OPEN:
            if asyncio.get_event_loop().time() - self.last_failure_time > self.recovery_timeout:
                self.state = CircuitState.HALF_OPEN
            else:
                raise Exception("Circuit breaker is OPEN")
        
        try:
            result = await func(*args, **kwargs)
            self._on_success()
            return result
        except Exception as e:
            self._on_failure()
            raise e
    
    def _on_success(self):
        self.failure_count = 0
        self.state = CircuitState.CLOSED
    
    def _on_failure(self):
        self.failure_count += 1
        self.last_failure_time = asyncio.get_event_loop().time()
        if self.failure_count >= self.failure_threshold:
            self.state = CircuitState.OPEN

# Usage example
async def unreliable_service():
    """Simulate an unreliable service"""
    import random
    if random.random() < 0.7:  # 70% failure rate
        raise Exception("Service unavailable")
    return "Success"

async def main():
    breaker = CircuitBreaker(failure_threshold=2, recovery_timeout=2.0)
    
    for i in range(10):
        try:
            result = await breaker.call(unreliable_service)
            print(f"Call {i+1}: {result}")
        except Exception as e:
            print(f"Call {i+1}: Failed - {e}")
        await asyncio.sleep(0.5)

# asyncio.run(main())
Exercise: Implement a Simple Agent Communication System

Create a communication system with the following requirements:

  • Implement a Message class with sender, recipient, content, and timestamp
  • Create an Agent class that can send and receive messages
  • Implement a MessageRouter that routes messages between agents
  • Add support for both direct messages and broadcast messages
  • Include basic error handling for invalid recipients

Test your system by creating at least 3 agents that exchange messages.

import asyncio
from datetime import datetime
from typing import Dict, List, Optional
from dataclasses import dataclass

@dataclass
class Message:
    sender: str
    recipient: str
    content: str
    timestamp: datetime = None
    is_broadcast: bool = False
    
    def __post_init__(self):
        if self.timestamp is None:
            self.timestamp = datetime.now()

class Agent:
    def __init__(self, name: str, router: 'MessageRouter'):
        self.name = name
        self.router = router
        self.inbox: List[Message] = []
        self.router.register_agent(self)
    
    async def send(self, recipient: str, content: str):
        """Send a direct message"""
        message = Message(
            sender=self.name,
            recipient=recipient,
            content=content
        )
        await self.router.route_message(message)
    
    async def broadcast(self, content: str):
        """Broadcast message to all agents"""
        message = Message(
            sender=self.name,
            recipient="*",
            content=content,
            is_broadcast=True
        )
        await self.router.route_message(message)
    
    async def receive(self, message: Message):
        """Receive a message"""
        self.inbox.append(message)
        print(f"[{self.name}] Received from {message.sender}: {message.content}")
    
    def get_messages(self) -> List[Message]:
        """Get all received messages"""
        return self.inbox.copy()

class MessageRouter:
    def __init__(self):
        self.agents: Dict[str, Agent] = {}
    
    def register_agent(self, agent: Agent):
        """Register an agent with the router"""
        self.agents[agent.name] = agent
        print(f"Agent registered: {agent.name}")
    
    async def route_message(self, message: Message):
        """Route message to appropriate recipient(s)"""
        if message.is_broadcast:
            # Send to all agents except sender
            for name, agent in self.agents.items():
                if name != message.sender:
                    await agent.receive(message)
        else:
            # Direct message
            if message.recipient in self.agents:
                await self.agents[message.recipient].receive(message)
            else:
                print(f"Error: Agent '{message.recipient}' not found")

# Test the system
async def main():
    router = MessageRouter()
    
    # Create agents
    agent1 = Agent("Alice", router)
    agent2 = Agent("Bob", router)
    agent3 = Agent("Charlie", router)
    
    # Send direct messages
    await agent1.send("Bob", "Hello Bob!")
    await agent2.send("Alice", "Hi Alice!")
    
    # Broadcast message
    await agent3.broadcast("Meeting at 3 PM!")
    
    # Check messages
    print(f"\nAlice's messages: {len(agent1.get_messages())}")
    print(f"Bob's messages: {len(agent2.get_messages())}")
    print(f"Charlie's messages: {len(agent3.get_messages())}")

# Run the test

Key Takeaways

  • Communication patterns define how agents interact and share information
  • Request-Response is simple but creates tight coupling between agents
  • Publish-Subscribe decouples agents and enables event-driven architectures
  • Pipeline patterns are ideal for sequential data processing workflows
  • Blackboard patterns enable collaborative problem-solving with shared state
  • Asynchronous communication is essential for scalable agent systems
  • Error handling patterns like circuit breakers prevent cascade failures
  • Choose the simplest pattern that meets your requirements
