LangChain Overview

Learn about langchain overview.

What is LangChain?

LangChain is a powerful open-source framework designed to help developers build applications powered by large language models (LLMs). Think of it as a toolkit that connects your language models to external data sources, tools, and workflows — making it much easier to build everything from chatbots to complex AI agent pipelines.

Instead of writing boilerplate code every time you want to integrate an LLM with a database, API, or custom tool, LangChain provides standardized abstractions and pre-built components that handle the heavy lifting for you.

Why LangChain Matters: Before frameworks like LangChain, building LLM-powered applications required manually managing prompts, API calls, memory, and tool integrations. LangChain abstracts these patterns into reusable, composable components.

Core Concepts of LangChain

LangChain is built around several key abstractions. Understanding these will give you a solid foundation for building AI agents and LLM applications.

1. Models

LangChain provides a unified interface for interacting with various LLM providers — OpenAI, Anthropic, Hugging Face, Google, and many others. You can swap between providers with minimal code changes.

from langchain_openai import ChatOpenAI
from langchain_anthropic import ChatAnthropic

# Using OpenAI's GPT-4
openai_llm = ChatOpenAI(model="gpt-4", temperature=0.7)

# Using Anthropic's Claude
claude_llm = ChatAnthropic(model="claude-3-sonnet-20240229", temperature=0.7)

# Both can be called the same way
response = openai_llm.invoke("What is an AI agent?")
print(response.content)

2. Prompts

LangChain offers a structured way to create and manage prompts using PromptTemplate. This makes it easy to dynamically inject variables into your prompts without messy string concatenation.

from langchain_core.prompts import PromptTemplate

template = PromptTemplate(
    input_variables=["topic", "audience"],
    template="Explain {topic} to a {audience} in 3 sentences or less."
)

formatted = template.format(topic="neural networks", audience="10-year-old")
print(formatted)
# Output: "Explain neural networks to a 10-year-old in 3 sentences or less."

response = openai_llm.invoke(formatted)
print(response.content)

3. Chains

Chains are sequences of operations that combine prompts, models, and other processing steps. The simplest chain is an LLMChain, which takes a prompt template and a model, then runs them together.

from.chains import LLMChain

# Older style (still widely used)
chain = LLMChain(llm=openai_llm, prompt=template)
result = chain.run(topic="quantum computing", audience="college student")
print(result)

# Modern LCEL style (recommended)
chain = template | openai_llm
result = chain.invoke({"topic": "quantum computing", "audience": "college student"})
print(result.content)
Pro Tip: LangChain now recommends using LCEL (LangChain Expression Language) with the pipe operator (|) to build chains. It's more readable, supports streaming, and enables parallel execution.

4. Memory

By default, LLMs are stateless — they don't remember previous interactions. LangChain's Memory components allow your application to retain context across conversation turns.

from langchain.memory import ConversationBufferMemory
from langchain.chains import ConversationChain

memory = ConversationBufferMemory(return_messages=True)

conversation = ConversationChain(
    llm=openai_llm,
    memory=memory,
    verbose=True
)

# First turn
response1 = conversation.predict(input="My name is Alex.")
print(response1)

# Second turn — the model remembers your name!
response2 = conversation.predict(input="What's my name?")
print(response2)
# Output: "Your name is Alex! You told me that earlier."

5. Tools

Tools are functions that your LLM can call to perform actions beyond text generation — searching the web, querying databases, making calculations, or calling APIs. This is the foundation of building AI agents.

from langchain_core.tools import tool

@tool
def get_weather(city: str) -> str:
    """Get the current weather for a given city."""
    # In a real app, you'd call a weather API here
    return f"The weather in {city} is 72°F and sunny."

@tool
def calculate(expression: str) -> str:
    """Evaluate a mathematical expression."""
    try:
        result = eval(expression)
        return f"The result is {result}"
    except Exception as e:
        return f"Error: {e}"

tools = [get_weather, calculate]
print(get_weather.args)
# {'city': {'title': 'City', 'type': 'str'}}

6. Agents

An agent is an LLM that can decide which tools to use and in what order to accomplish a task. Instead of a fixed chain of operations, the agent reasons about what to do next, takes an action, observes the result, and repeats until the task is complete.

from langchain.agents import create_tool_calling_agent, AgentExecutor
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant with access to tools."),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}")
])

agent = create_tool_calling_agent(openai_llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

result = agent_executor.invoke({
    "input": "What's the weather in Tokyo and what's 25 * 17?"
})
print(result["output"])
Important: Not all models support tool-calling natively. Make sure you use a model that has been fine-tuned for function calling, such as GPT-4, Claude, or Gemini. Using a model without tool-calling support will result in errors.

LangChain vs. Other Frameworks

LangChain isn't the only framework for building LLM applications. Here's how it compares to other popular options:

LangChain's Ecosystem

LangChain is more than a single library — it's an ecosystem of packages that work together:

  • langchain-core: Base abstractions and LCEL. Lightweight and essential.
  • langchain: Higher-level chains, agents, and retrieval logic.
  • langchain-openai / langchain-anthropic: Provider-specific integrations.
  • LangGraph: Extension for building stateful, multi-agent workflows with graph-based control flow.
  • LangSmith: Observability and debugging platform for LangChain applications.
  • LangServe: Deploy chains as REST APIs with a single command.

Building Your First LangChain Agent

Let's put it all together by building a simple agent that can search for information and perform calculations.

from langchain_openai import ChatOpenAI
from langchain_core.tools import tool
from langchain.agents import create_tool_calling_agent, AgentExecutor
from langchain_core.prompts import ChatPromptTemplate

# Define tools
@tool
def search_web(query: str) -> str:
    """Search the web for information about a topic."""
    # Simulated search results
    results = {
        "python": "Python is a versatile programming language created by Guido van Rossum in 1991.",
        "langchain": "LangChain is a framework for building LLM-powered applications.",
        "ai agents": "AI agents are autonomous systems that can reason, plan, and use tools."
    }
    for key, value in results.items():
        if key in query.lower():
            return value
    return f"No results found for '{query}'."

@tool
def calculator(expression: str) -> str:
    """Calculate a mathematical expression."""
    try:
        return str(eval(expression))
    except:
        return "Invalid expression."

# Set up the model and agent
llm = ChatOpenAI(model="gpt-4", temperature=0)

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a research assistant. Use tools to find information and perform calculations."),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}")
])

tools = [search_web, calculator]
agent = create_tool_calling_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# Run the agent
result = executor.invoke({
    "input": "Tell me about LangChain and also calculate 144 / 12 + 8"
})
print(result["output"])
What Just Happened? The agent received the user input, decided to call the search_web tool for the LangChain query, called the calculator tool for the math, and then synthesized both results into a coherent response. This is the power of agentic workflows!

Exercise: Create a Custom Tool and Agent

Create a new tool called word_count that takes a string and returns the number of words in it. Then, integrate this tool into an agent alongside the calculator tool we defined above. Test it by asking the agent to count the words in a sentence and perform a calculation.

Requirements:

  • Define the word_count tool using the @tool decorator
  • Include a proper docstring so the LLM understands what the tool does
  • Create an agent that has access to both word_count and calculator
  • Test with an input that requires both tools
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI
from langchain.agents import create_tool_calling_agent, AgentExecutor
from langchain_core.prompts import ChatPromptTemplate

@tool
def word_count(text: str) -> str:
    """Count the number of words in a given text string."""
    count = len(text.split())
    return f"The text contains {count} words."

@tool
def calculator(expression: str) -> str:
    """Calculate a mathematical expression."""
    try:
        return str(eval(expression))
    except:
        return "Invalid expression."

llm = ChatOpenAI(model="gpt-4", temperature=0)

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant. Use tools when needed."),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}")
])

tools = [word_count, calculator]
agent = create_tool_calling_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

result = executor.invoke({
    "input": "Count the words in 'The quick brown fox jumps over the lazy dog' and multiply that by 3"
})
print(result["output"])
# Expected: Agent counts 9 words, calculates 9 * 3 = 27

Common Pitfalls and Best Practices

As you start building with LangChain, keep these tips in mind:

  • Always set temperature appropriately: Use temperature=0 for factual, deterministic responses. Use higher values (0.7–1.0) for creative tasks.
  • Use verbose=True during development: This shows you the agent's reasoning process, tool calls, and intermediate steps — invaluable for debugging.
  • Write clear tool docstrings: The LLM reads your docstrings to understand what each tool does. Be specific and descriptive.
  • Handle errors gracefully: Tools can fail. Make sure your tool functions return meaningful error messages rather than raising exceptions.
  • Be mindful of token limits: Long conversations or large tool outputs can exceed the model's context window. Use ConversationSummaryMemory or truncate inputs when needed.
Security Warning: Never use eval() on untrusted input in production code. The calculator example above is for demonstration only. In a real application, use a safe math parsing library like simpleeval.

Key Takeaways

  • LangChain is a comprehensive framework for building LLM-powered applications with standardized abstractions for models, prompts, chains, memory, tools, and agents.
  • PromptTemplates allow you to dynamically build prompts with variable injection, keeping your code clean and maintainable.
  • Chains (especially using LCEL with the | operator) let you compose prompts, models, and processors into reusable pipelines.
  • Memory components give your LLM applications the ability to retain context across conversation turns, enabling natural multi-turn interactions.
  • Tools extend your LLM's capabilities beyond text generation, allowing it to perform calculations, search data, call APIs, and more.
  • Agents combine LLMs with tools, enabling the model to autonomously decide which actions to take and in what order to complete complex tasks.
  • The LangChain ecosystem includes LangGraph for complex workflows, LangSmith for observability, and LangServe for deployment — all designed to work together seamlessly.
  • LangChain competes with frameworks like LlamaIndex (focused on RAG) and Semantic Kernel (enterprise-focused), but stands out for its agent-building capabilities and broad provider support.
