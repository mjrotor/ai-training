Static Analysis Integration

Learn about static analysis integration.

What Is Static Analysis?

Static analysis is the process of examining source code without executing it. Instead of running the program, a static analyzer reads the code structure, checks patterns, and flags potential issues such as syntax errors, type mismatches, security vulnerabilities, or style violations. Think of it as a proofreader that scans your manuscript before anyone reads it aloud.

In the context of AI agents, static analysis becomes a powerful tool. When an AI agent writes or modifies code, we can automatically verify that the generated code is safe, correct, and follows best practices — all before it ever runs.

Why Integrate Static Analysis into AI Agents?

AI agents are increasingly responsible for generating, reviewing, and deploying code. Without guardrails, an agent might produce code that:

  • Contains subtle bugs that only appear at runtime
  • Introduces security vulnerabilities (e.g., SQL injection, hardcoded secrets)
  • Violates project coding standards
  • Uses deprecated or unsafe library functions

By integrating static analysis into the agent's workflow, we create a feedback loop: the agent writes code, the analyzer checks it, and the agent refixes any flagged issues — all automatically.

Key Idea: Static analysis integration turns an AI agent from a "code generator" into a "code quality guardian." The agent doesn't just write code — it self-corrects based on analyzer feedback.

Building a Static Analysis Pipeline for Your Agent

Let's build a practical pipeline that an AI agent can use to check and improve generated code. The pipeline will:

  1. Receive a code snippet from the agent
  2. Run it through multiple static analyzers
  3. Collect and categorize the results
  4. Provide actionable feedback for the agent to fix issues

Step 1: Setting Up the Analyzer Module

import subprocess
import json
import tempfile
import os
from dataclasses import dataclass, field
from typing import List, Optional
from enum import Enum


class Severity(Enum):
    INFO = "info"
    WARNING = "warning"
    ERROR = "error"
    CRITICAL = "critical"


@dataclass
class AnalysisIssue:
    tool: str
    file: str
    line: int
    message: str
    severity: Severity
    rule_id: Optional[str] = None


@dataclass
class AnalysisReport:
    issues: List[AnalysisIssue] = field(default_factory=list)
    
    @property
    def error_count(self) -> int:
        return sum(1 for i in self.issues 
                   if i.severity in (Severity.ERROR, Severity.CRITICAL))
    
    @property
    def warning_count(self) -> int:
        return sum(1 for i in self.issues 
                   if i.severity == Severity.WARNING)
    
    @property
    def is_clean(self) -> bool:
        return self.error_count == 0
    
    def summary(self) -> str:
        return (
            f"Report: {len(self.issues)} issues found — "
            f"{self.error_count} errors, {self.warning_count} warnings"
        )

Step 2: Running Individual Analyzers

class StaticAnalyzer:
    """Orchestrates multiple static analysis tools."""
    
    def __init__(self, tools: Optional[List[str]] = None):
        self.tools = tools or ["ruff", "bandit", "pyflakes"]
    
    def _write_temp_file(self, code: str) -> str:
        """Write code to a temporary file for analysis."""
        tmp = tempfile.NamedTemporaryFile(
            mode="w", suffix=".py", delete=False
        )
        tmp.write(code)
        tmp.close()
        return tmp.name
    
    def _run_ruff(self, filepath: str) -> List[AnalysisIssue]:
        """Run Ruff linter on the given file."""
        issues = []
        try:
            result = subprocess.run(
                ["ruff", "check", "--output-format", "json", filepath],
                capture_output=True, text=True, timeout=30
            )
            if result.stdout.strip():
                for item in json.loads(result.stdout):
                    severity = (
                        Severity.ERROR if item["code"] 
                        and item["code"].startswith("E")
                        else Severity.WARNING
                    )
                    issues.append(AnalysisIssue(
                        tool="ruff",
                        file=filepath,
                        line=item["location"]["row"],
                        message=item["message"],
                        severity=severity,
                        rule_id=item["code"]
                    ))
        except FileNotFoundError:
            issues.append(AnalysisIssue(
                tool="ruff", file=filepath, line=0,
                message="Ruff not installed. Run: pip install ruff",
                severity=Severity.INFO
            ))
        return issues
    
    def _run_bandit(self, filepath: str) -> List[AnalysisIssue]:
        """Run Bandit security checker on the given file."""
        issues = []
        try:
            result = subprocess.run(
                ["bandit", "-f", "json", filepath],
                capture_output=True, text=True, timeout=30
            )
            data = json.loads(result.stdout)
            for item in data.get("results", []):
                severity = (
                    Severity.CRITICAL if item["issue_severity"] == "HIGH"
                    else Severity.WARNING if item["issue_severity"] == "MEDIUM"
                    else Severity.INFO
                )
                issues.append(AnalysisIssue(
                    tool="bandit",
                    file=filepath,
                    line=item["line_number"],
                    message=item["issue_text"],
                    severity=severity,
                    rule_id=item["test_id"]
                ))
        except FileNotFoundError:
            issues.append(AnalysisIssue(
                tool="bandit", file=filepath, line=0,
                message="Bandit not installed. Run: pip install bandit",
                severity=Severity.INFO
            ))
        return issues
    
    def _run_pyflakes(self, filepath: str) -> List[AnalysisIssue]:
        """Run Pyflakes on the given file."""
        issues = []
        try:
            result = subprocess.run(
                ["pyflakes", filepath],
                capture_output=True, text=True, timeout=30
            )
            for line in result.stdout.strip().split("\n"):
                if line:
                    issues.append(AnalysisIssue(
                        tool="pyflakes",
                        file=filepath, line=0,
                        message=line,
                        severity=Severity.WARNING
                    ))
        except FileNotFoundError:
            issues.append(AnalysisIssue(
                tool="pyflakes", file=filepath, line=0,
                message="Pyflakes not installed. Run: pip install pyflakes",
                severity=Severity.INFO
            ))
        return issues
    
    def analyze(self, code: str) -> AnalysisReport:
        """Run all configured analyzers on the given code."""
        filepath = self._write_temp_file(code)
        all_issues = []
        
        try:
            tool_map = {
                "ruff": self._run_ruff,
                "bandit": self._run_bandit,
                "pyflakes": self._run_pyflakes,
            }
            
            for tool in self.tools:
                if tool in tool_map:
                    all_issues.extend(tool_map[tool](filepath))
        finally:
            os.unlink(filepath)  # Clean up temp file
        
        return AnalysisReport(issues=all_issues)
Pro Tip: Always clean up temporary files after analysis. The finally block ensures the temp file is deleted even if an analyzer crashes. In production, consider using a context manager or a dedicated scratch directory.

Step 3: Creating the Feedback Loop

The real power comes from feeding the analysis results back to the AI agent so it can self-correct. Here's how that feedback loop works:

class AgentCodeReviewer:
    """Connects an AI agent to the static analysis pipeline."""
    
    def __init__(self, max_iterations: int = 3):
        self.analyzer = StaticAnalyzer(
            tools=["ruff", "bandit", "pyflakes"]
        )
        self.max_iterations = max_iterations
    
    def _format_issues_for_agent(
        self, report: AnalysisReport
    ) -> str:
        """Convert analysis report into a prompt-friendly format."""
        if report.is_clean:
            return "No issues found. Code looks clean!"
        
        lines = [report.summary(), "\nIssues to fix:\n"]
        
        # Group by severity (errors first)
        for severity in [
            Severity.CRITICAL, Severity.ERROR, 
            Severity.WARNING, Severity.INFO
        ]:
            filtered = [
                i for i in report.issues if i.severity == severity
            ]
            if filtered:
                lines.append(f"--- {severity.value.upper()} ---")
                for issue in filtered:
                    lines.append(
                        f"  Line {issue.line}: [{issue.tool}] "
                        f"{issue.message} (Rule: {issue.rule_id})"
                    )
                lines.append("")
        
        return "\n".join(lines)
    
    def review_and_fix(
        self, 
        code: str, 
        agent_fix_function
    ) -> dict:
        """
        Run the analyze-fix loop.
        
        agent_fix_function: A callable that takes 
        (original_code, feedback) and returns fixed_code.
        """
        current_code = code
        history = []
        
        for iteration in range(1, self.max_iterations + 1):
            report = self.analyzer.analyze(current_code)
            feedback = self._format_issues_for_agent(report)
            
            history.append({
                "iteration": iteration,
                "issues_count": len(report.issues),
                "code": current_code,
                "feedback": feedback
            })
            
            if report.is_clean:
                break
            
            # Ask the agent to fix the issues
            current_code = agent_fix_function(
                current_code, feedback
            )
        
        return {
            "final_code": current_code,
            "iterations": len(history),
            "final_report": self.analyzer.analyze(current_code),
            "history": history
        }

Handling Common Static Analysis Patterns

AI agents frequently encounter the same categories of issues. Let's look at the most common ones and how to address them.

Security Vulnerabilities

Security issues are the most critical to catch. Bandit excels at finding these:


# ❌ BAD: Common security mistakes an agent might generate

import os
import sqlite3

# Dangerous: command injection vulnerability
def run_command(user_input):
    os.system(f"echo {user_input}")  # Bandit: B602

# Dangerous: hardcoded secret
API_KEY = "sk-1234567890abcdef"  # Bandit: B105

# Dangerous: SQL injection
def get_user(username):
    conn = sqlite3.connect("app.db")
    cursor = conn.cursor()
    cursor.execute(
        f"SELECT * FROM users WHERE name = '{username}'"
    )  # Bandit: B608
    return cursor.fetchone()


# ✅ GOOD: Fixed versions

import subprocess
import sqlite3
import os

# Safe: use subprocess with argument list
def run_command(user_input):
    subprocess.run(["echo", user_input], shell=False)

# Safe: load secret from environment
API_KEY = os.environ.get("API_KEY")

# Safe: parameterized query
def get_user(username):
    conn = sqlite3.connect("app.db")
    cursor = conn.cursor()
    cursor.execute(
        "SELECT * FROM users WHERE name = ?", (username,)
    )
    return cursor.fetchone()
Warning: Never trust AI-generated code to be secure by default. Always run security-focused static analysis (like Bandit) on any code an AI agent produces, especially if it handles user input, database queries, or system commands.

Integrating with an AI Agent Framework

Let's see how to plug this into a real agent workflow. Here's an example using a simple agent that generates Python functions:

class CodeGeneratingAgent:
    """A simple agent that generates and self-corrects code."""
    
    def __init__(self):
        self.reviewer = AgentCodeReviewer(max_iterations=3)
    
    def generate_function(
        self, 
        description: str,
        llm_generate_func
    ) -> str:
        """
        Generate a function and ensure it passes 
        static analysis.
        
        llm_generate_func: callable that takes a prompt 
        and returns code string.
        """
        # Initial generation
        prompt = (
            f"Write a Python function that {description}. "
            "Include type hints and a docstring."
        )
        initial_code = llm_generate_func(prompt)
        
        # Define how the agent should fix code given feedback
        def fix_code(code: str, feedback: str) -> str:
            fix_prompt = (
                f"Here is code:\n\n{code}\n\n"
                f"Static analysis found these issues:\n{feedback}\n\n"
                "Please fix all issues. Return ONLY the "
                "corrected code, no explanation."
            )
            return llm_generate_func(fix_prompt)
        
        # Run the review-and-fix loop
        result = self.reviewer.review_and_fix(
            initial_code, fix_code
        )
        
        print(f"Completed in {result['iterations']} iterations")
        print(result["final_report"].summary())
        
        return result["final_code"]


# --- Usage Example ---
# In practice, llm_generate_func would call an actual LLM API

def mock_llm(prompt: str) -> str:
    """Simulates an LLM response for demonstration."""
    return '''
def add_numbers(a, b):
    result = a + b
    return result
'''

agent = CodeGeneratingAgent()
clean_code = agent.generate_function(
    description="adds two numbers together",
    llm_generate_func=mock_llm
)
print(clean_code)
Architecture Note: The AgentCodeReviewer is tool-agnostic — it doesn't care whether the code was written by a human, a simple template, or a sophisticated LLM. This makes it reusable across many agent architectures.

from typing import List

# Define severity order for comparison
SEVERITY_ORDER = {
    Severity.INFO: 0,
    Severity.WARNING: 1,
    Severity.ERROR: 2,
    Severity.CRITICAL: 3,
}

def filter_issues(
    report: AnalysisReport,
    tools: List[str],
    min_severity: Severity
) -> AnalysisReport:
    """Filter analysis report by tool and minimum severity."""
    min_level = SEVERITY_ORDER[min_severity]
    
    filtered = [
        issue for issue in report.issues
        if issue.tool in tools
        and SEVERITY_ORDER[issue.severity] >= min_level
    ]
    
    # Sort by line number ascending
    filtered.sort(key=lambda i: i.line)
    
    return AnalysisReport(issues=filtered)

Performance Considerations

When running static analysis inside an agent loop, speed matters. Here are strategies to keep your pipeline fast:

  • Use Ruff over Flake8/Pyflakes when possible — Ruff is written in Rust and can be 10–100× faster than equivalent Python linters.
  • Cache results — If the agent generates the same code twice, don't re-analyze. Use a hash of the code as a cache key.
  • Run analyzers in parallel — Since tools are independent, use concurrent.futures to run them simultaneously.
  • Limit scope — Only analyze the files the agent actually changed, not the entire project.
  • Use incremental analysis — Some tools (like MyPy) support incremental mode that only re-checks changed files.

import concurrent.futures

class ParallelStaticAnalyzer(StaticAnalyzer):
    """Runs analyzers in parallel for better performance."""
    
    def analyze(self, code: str) -> AnalysisReport:
        filepath = self._write_temp_file(code)
        all_issues = []
        
        tool_map = {
            "ruff": self._run_ruff,
            "bandit": self._run_bandit,
            "pyflakes": self._run_pyflakes,
        }
        
        try:
            with concurrent.futures.ThreadPoolExecutor(
                max_workers=len(self.tools)
            ) as executor:
                futures = {
                    executor.submit(tool_map[tool], filepath): tool
                    for tool in self.tools
                    if tool in tool_map
                }
                for future in concurrent.futures.as_completed(
                    futures
                ):
                    all_issues.extend(future.result())
        finally:
            os.unlink(filepath)
        
        return AnalysisReport(issues=all_issues)
Benchmark Tip: On a typical 500-line Python file, Ruff completes in ~10ms, Pyflakes in ~50ms, and Bandit in ~500ms. Running them in parallel means total time is bounded by the slowest tool (~500ms), not the sum (~560ms).

Key Takeaways

  • Static analysis examines code without running it, catching bugs, security issues, and style violations before execution.
  • Integrating static analysis into AI agent workflows creates a self-correcting loop where the agent writes code, receives feedback, and fixes issues automatically.
  • Different tools serve different purposes — use Ruff for fast linting, Bandit for security, Pyflakes for error detection, and MyPy for type checking.
  • The feedback loop pattern (analyze → report → fix → re-analyze) is the core architecture for agent-driven code quality.
  • Always configure analysis rules to match your project's needs — don't blindly enable every rule.
  • Performance optimization matters in agent loops: use parallel execution, caching, and incremental analysis to keep things fast.
  • Security analysis is non-negotiable — any AI-generated code that touches user input, databases, or system commands must pass security checks.
