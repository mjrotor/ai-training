Source Evaluation

Learn about source evaluation.

Why Source Evaluation Matters for AI Agents

When an AI agent retrieves information from the web, databases, or user inputs, not all sources are created equal. A critical skill for building reliable AI systems is source evaluation — the ability to assess the credibility, relevance, and timeliness of information before acting on it.

Without proper source evaluation, your AI agent might:

  • Act on outdated or incorrect data
  • Trust biased or unreliable sources
  • Make decisions based on irrelevant context
  • Propagate misinformation to end users

In this lesson, you'll learn how to implement source evaluation techniques in your AI agent workflows using Python.

Core Principles of Source Evaluation

Before writing code, let's establish the key dimensions we use to evaluate any information source:

Dimension What to Check Example Question
Authority Who created the source? "Is this from a recognized expert or institution?"
Accuracy Is the information correct? "Can this be verified against other sources?"
Currency How recent is the information? "Is this data from the last 6 months?"
Relevance Does it match the query? "Does this actually answer the user's question?"
Bias Is there a hidden agenda? "Does this source have a commercial or political motive?"
💡 Did you know? Large language models like me can sometimes "hallucinate" — generating plausible-sounding but incorrect information. Source evaluation helps catch these errors before they reach your users.

Building a Source Evaluator in Python

Let's create a SourceEvaluator class that scores sources across multiple dimensions. We'll use a simple 0-100 scale for each dimension.

from dataclasses import dataclass
from datetime import datetime, timedelta
from typing import Optional

@dataclass
class Source:
    """Represents an information source."""
    url: str
    title: str
    content: str
    author: str
    published_date: datetime
    domain: str
    is_verified: bool = False

class SourceEvaluator:
    """Evaluates the quality of information sources."""
    
    # Trusted domains for demonstration
    TRUSTED_DOMAINS = {
        'arxiv.org', 'nature.com', 'science.org',
        'who.int', 'cdc.gov', 'nih.gov',
        'mit.edu', 'stanford.edu', 'harvard.edu'
    }
    
    def __init__(self, max_age_days: int = 180):
        self.max_age_days = max_age_days
    
    def evaluate_authority(self, source: Source) -> int:
        """Score source authority (0-100)."""
        score = 0
        
        # Check if from a trusted domain
        if source.domain in self.TRUSTED_DOMAINS:
            score += 60
        
        # Bonus for verified authors
        if source.is_verified:
            score += 30
        
        # Small bonus for having an author listed
        if source.author and source.author.strip():
            score += 10
        
        return min(score, 100)
    
    def evaluate_currency(self, source: Source) -> int:
        """Score how recent the information is (0-100)."""
        age = datetime.now() - source.published_date
        
        if age.days <= 7:
            return 100
        elif age.days <= 30:
            return 85
        elif age.days <= 90:
            return 70
        elif age.days <= self.max_age_days:
            return 50
        else:
            return max(0, 100 - (age.days - self.max_age_days))
    
    def evaluate_relevance(self, source: Source, query: str) -> int:
        """Score how relevant the source is to the query (0-100)."""
        query_words = set(query.lower().split())
        content_words = set(source.content.lower().split())
        title_words = set(source.title.lower().split())
        
        # Count matching words
        content_matches = len(query_words & content_words)
        title_matches = len(query_words & title_words)
        
        # Title matches are more important
        score = (content_matches * 5) + (title_matches * 15)
        return min(score, 100)
    
    def evaluate(self, source: Source, query: str) -> dict:
        """Run all evaluations and return scores."""
        return {
            'authority': self.evaluate_authority(source),
            'currency': self.evaluate_currency(source),
            'relevance': self.evaluate_relevance(source, query),
            'overall': 0  # Calculated below
        }
    
    def get_overall_score(self, scores: dict) -> int:
        """Calculate weighted overall score."""
        weights = {
            'authority': 0.35,
            'currency': 0.25,
            'relevance': 0.40
        }
        
        overall = sum(
            scores[dim] * weight 
            for dim, weight in weights.items()
        )
        return int(overall)

Using the Source Evaluator

Here's how to use our evaluator with real sources:

# Create an evaluator that prefers recent sources
evaluator = SourceEvaluator(max_age_days=90)

# Example source
source = Source(
    url="https://arxiv.org/abs/2024.12345",
    title="Advances in Transformer Architecture for NLP",
    content="This paper explores new attention mechanisms...",
    author="Dr. Jane Smith",
    published_date=datetime(2024, 1, 15),
    domain="arxiv.org",
    is_verified=True
)

# Evaluate against a user query
query = "transformer architecture improvements"
scores = evaluator.evaluate(source, query)
scores['overall'] = evaluator.get_overall_score(scores)

print(f"Source: {source.title}")
print(f"  Authority: {scores['authority']}/100")
print(f"  Currency:  {scores['currency']}/100")
print(f"  Relevance: {scores['relevance']}/100")
print(f"  Overall:   {scores['overall']}/100")
💡 Pro Tip: Adjust the weights in get_overall_score() based on your use case. For medical queries, you might increase the authority weight. For news queries, increase currency.

Implementing Source Comparison

Often, your agent will retrieve multiple sources. Let's add comparison functionality:

def rank_sources(
    self, 
    sources: list[Source], 
    query: str,
    min_score: int = 50
) -> list[tuple[Source, dict]]:
    """
    Rank multiple sources by overall quality.
    
    Args:
        sources: List of Source objects to evaluate
        query: The user's original query
        min_score: Minimum overall score to include
        
    Returns:
        List of (source, scores) tuples, sorted by overall score
    """
    results = []
    
    for source in sources:
        scores = self.evaluate(source, query)
        scores['overall'] = self.get_overall_score(scores)
        
        if scores['overall'] >= min_score:
            results.append((source, scores))
    
    # Sort by overall score (highest first)
    results.sort(key=lambda x: x[1]['overall'], reverse=True)
    return results

# Add this method to the SourceEvaluator class
SourceEvaluator.rank_sources = rank_sources

Handling Edge Cases

Real-world sources can be messy. Here's how to handle common edge cases:

def safe_evaluate(self, source: Optional[Source], query: str) -> dict:
    """
    Safely evaluate a source, handling None and missing data.
    """
    # Default low scores for missing/invalid sources
    default_scores = {
        'authority': 0,
        'currency': 0,
        'relevance': 0,
        'overall': 0,
        'error': 'No source provided'
    }
    
    if source is None:
        return default_scores
    
    try:
        scores = self.evaluate(source, query)
        scores['overall'] = self.get_overall_score(scores)
        return scores
    except Exception as e:
        # Log the error in production
        default_scores['error'] = str(e)
        return default_scores

# Add to class
SourceEvaluator.safe_evaluate = safe_evaluate

  • Known news domains get a neutral score

def evaluate_bias(self, source: Source) -> int:
    """Score potential bias (100 = least biased)."""
    # Academic/government sources
    if source.domain.endswith(('.edu', '.gov', '.ac.uk')):
        return 90
    
    # Known neutral sources
    neutral_domains = {'reuters.com', 'ap.org', 'bbc.com'}
    if source.domain in neutral_domains:
        return 70
    
    # Commercial sources (potential commercial bias)
    if source.domain.endswith(('.com', '.io')):
        return 40
    
    # Default for unknown domains
    return 50

def get_overall_score(self, scores: dict) -> int:
    """Updated to include bias dimension."""
    weights = {
        'authority': 0.30,
        'currency': 0.20,
        'relevance': 0.35,
        'bias': 0.15
    }
    
    overall = sum(
        scores.get(dim, 0) * weight 
        for dim, weight in weights.items()
    )
    return int(overall)

# Add to class
SourceEvaluator.evaluate_bias = evaluate_bias

Key Takeaways

  • Source evaluation is essential for building trustworthy AI agents that don't propagate misinformation
  • Multiple dimensions matter: Authority, currency, relevance, and bias all contribute to source quality
  • Weighted scoring lets you customize evaluation for different use cases (medical vs. news vs. general)
  • Always handle edge cases: Missing data, None sources, and exceptions should return safe defaults
  • Automated evaluation has limits: Combine with human review for critical applications
  • Ranking multiple sources helps your agent choose the best information when options conflict
