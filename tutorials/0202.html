Setting Up Your API Key

Learn about setting up your api key.

What Is an API Key?

An API key is a unique identifier that authenticates your requests to a service — in our case, an AI provider such as OpenAI, Anthropic, or Google. Think of it like a password that tells the provider, "This request is coming from me, and I have permission to use this service."

Without a valid API key, the provider's servers will reject every request you send. Setting one up correctly is the single most important step before you can start building AI agents.

Choosing a Provider

There are several major providers that offer powerful language-model APIs. The table below compares the three we will reference throughout this course.

Provider Popular Model Free Tier? Docs URL
OpenAI GPT-4o / GPT-4o-mini Paid credits on sign-up platform.openai.com
Anthropic Claude 3.5 Sonnet No (pay-as-you-go) docs.anthropic.com
Google Gemini 1.5 Flash Yes (generous) ai.google.dev
Tip: If you are just starting out, Google's Gemini API offers a generous free tier and is a great way to experiment without spending money.

Step-by-Step: Obtaining Your Key

The exact steps vary by provider, but the general workflow is the same:

  1. Create an account on the provider's developer platform.
  2. Navigate to the API keys section (usually found under your account or project settings).
  3. Generate a new key and give it a descriptive name (e.g., ai-agent-course).
  4. Copy the key immediately — most providers only show the full key once.
Warning: Never share your API key publicly. If a key is accidentally exposed, revoke it immediately in your provider dashboard and generate a new one.

Storing Your Key Safely

Hard-coding an API key directly in your source code is a serious security risk, especially if you plan to push your code to a public repository. The standard practice is to use environment variables or a .env file.

Using a .env File

Create a file named .env in the root of your project:

# .env
OPENAI_API_KEY=sk-your-key-here

Then load it in Python with the python-dotenv package:

# main.py
from dotenv import load_dotenv
import os

load_dotenv()                       # reads variables from .env

api_key = os.getenv("OPENAI_API_KEY")

if not api_key:
    raise ValueError("OPENAI_API_KEY is not set in your .env file.")

print("API key loaded successfully!")

Installing python-dotenv

pip install python-dotenv
Why environment variables? They keep secrets out of version control. Add .env to your .gitignore file so it never gets committed to Git.

Making Your First Authenticated Request

With the key loaded, you can now call the provider's API. Below is a minimal example using the OpenAI Python SDK:

# call_openai.py
from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()
client = OpenAI()   # automatically reads OPENAI_API_KEY from env

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain what an API key is in one sentence."}
    ],
    max_tokens=60
)

print(response.choices[0].message.content)

Run the script:

python call_openai.py

If everything is set up correctly, you should see a short explanation of what an API key is printed to your terminal.

Note: If you receive a 401 Authentication Error, double-check that the key in your .env file matches exactly — no extra spaces or line breaks.

  2. Uses the google-generativeai SDK to ask Gemini 1.5 Flash: "What is an AI agent in two sentences?"

import google.generativeai as genai

Key Takeaways

  • An API key authenticates your requests to an AI provider — treat it like a password.
  • Use a .env file and python-dotenv to keep keys out of your source code.
  • Always add .env to your .gitignore to prevent accidental exposure.
  • Most Python SDKs (OpenAI, Anthropic, Google) automatically read the key from environment variables when you instantiate the client.
  • If you get a 401 error, verify the key string is correct and that the environment variable name matches what your code expects.
