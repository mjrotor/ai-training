Short-Term Memory

Learn about short-term memory.

What Is Short-Term Memory?

In AI agents, short-term memory refers to the information the agent can access during a single conversation or task session. It's like a scratchpad — the agent uses it to remember what you've said, what it has done, and what it needs to do next.

Think of it like your own working memory: you can hold a few ideas in your head while solving a problem, but once you walk away, they're gone. Similarly, an AI agent's short-term memory lasts only for the duration of the current interaction.

Why Short-Term Memory Matters

Without short-term memory, an AI agent would:

  • Forget what you said earlier in the conversation
  • Repeat itself or contradict previous statements
  • Be unable to follow multi-step instructions
  • Lose track of context when tasks get complex

Short-term memory is what makes conversations feel natural and coherent.

Example: A Conversation Without vs. With Memory

Without Memory With Memory
User: "My name is Alex."
Agent: "Nice to meet you, Alex!"

User: "What's my name?"
Agent: "I don't know your name."		 User: "My name is Alex."
Agent: "Nice to meet you, Alex!"

Agent: "Your name is Alex!"
Note: Short-term memory is temporary. Once the session ends, the agent typically forgets everything unless it has a long-term memory system to save important details.

How Short-Term Memory Works

At a technical level, short-term memory is usually implemented as a list of messages that grows as the conversation continues. Each message includes:

  • role: Who sent it — "user", "assistant", or "system"
  • content: The actual text of the message

Example: Message List Structure

messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "What's the weather like?"},
    {"role": "assistant", "content": "I don't have access to real-time weather data."},
    {"role": "user", "content": "Can you check a website for me?"}
]

Every time the agent responds, the new messages are added to this list. The entire list is sent to the AI model each time it needs to generate a response.

Tip: The longer the conversation, the more messages accumulate. This can slow things down and cost more tokens. We'll talk about managing this later!

Implementing Short-Term Memory in Python

Let's build a simple agent with short-term memory using a message list.

Step 1: Create a Basic Agent Class

class SimpleAgent:
    def __init__(self, system_prompt):
        self.messages = [{"role": "system", "content": system_prompt}]

    def chat(self, user_input):
        # Add user message to memory
        self.messages.append({"role": "user", "content": user_input})

        # Simulate a response (in real use, this would call an AI API)
        response = f"I heard: {user_input}"

        # Add assistant response to memory
        self.messages.append({"role": "assistant", "content": response})

        return response

# Create an agent
agent = SimpleAgent("You are a helpful assistant.")

# Chat with it
print(agent.chat("Hello!"))
print(agent.messages)

Step 2: View the Memory

You can inspect the agent's memory at any time:

for msg in agent.messages:
    print(f"[{msg['role']}]: {msg['content']}")
Warning: In a real application, you'd replace the simulated response with an actual API call to an AI model like GPT or Claude. The memory list would be passed along with each request.

Managing Memory Length

As conversations grow, the message list can become very long. Here are common strategies:

  • Keep all messages: Best for short conversations
  • Keep last N messages: Truncate older messages
  • Summarize old messages: Compress earlier context into a summary

Example: Truncating Old Messages

def trim_messages(messages, max_length=10):
    """Keep only the last max_length messages."""
    if len(messages) > max_length:
        return messages[-max_length:]
    return messages

# Example usage
long_messages = [{"role": "user", "content": f"Message {i}"} for i in range(20)]
trimmed = trim_messages(long_messages, max_length=5)
print(f"Original: {len(long_messages)}, Trimmed: {len(trimmed)}")
Exercise

Modify the SimpleAgent class to include a max_memory parameter. When the number of messages exceeds this limit, automatically remove the oldest messages (but always keep the system prompt).

class SimpleAgent:
    def __init__(self, system_prompt, max_memory=10):
        self.messages = [{"role": "system", "content": system_prompt}]
        self.max_memory = max_memory

    def chat(self, user_input):
        self.messages.append({"role": "user", "content": user_input})
        response = f"I heard: {user_input}"
        self.messages.append({"role": "assistant", "content": response})
        self._trim_memory()
        return response

    def _trim_memory(self):
        # Always keep system prompt (index 0), trim the rest
        if len(self.messages) > self.max_memory:
            self.messages = [self.messages[0]] + self.messages[-(self.max_memory - 1):]

Key Takeaways

  • Short-term memory lets an AI agent remember context during a conversation
  • It's typically implemented as a list of messages with roles and content
  • The entire message history is usually sent to the AI model with each request
  • Long conversations require memory management strategies like truncation or summarization
  • Short-term memory is temporary — it doesn't persist between sessions
