What Exactly is an AI Agent?

An AI agent is a software system that can perceive its environment, make decisions, and take actions to achieve specific goals — all with a degree of autonomy. Unlike traditional programs that follow rigid, pre-defined rules, AI agents can adapt, learn, and respond dynamically to new situations.

Think of it this way: A traditional calculator follows exact instructions every time. An AI agent is more like a personal assistant that understands context, makes judgment calls, and takes initiative.

Core Characteristics of AI Agents

Every AI agent shares several fundamental traits that distinguish them from ordinary software:

  • Autonomy: The ability to operate without constant human intervention. Once given a goal, the agent decides how to achieve it.
  • Perception: The capacity to sense or receive input from its environment — whether that's text, images, sensor data, or API responses.
  • Reasoning: The ability to process information, weigh options, and make decisions based on its goals and available data.
  • Action: The power to execute tasks — sending messages, calling APIs, writing files, or controlling physical devices.
  • Memory: The ability to retain information across interactions, enabling context-aware behavior over time.

AI Agents vs. Traditional Software

It's important to understand how AI agents differ from the programs you may already be familiar with. Here's a side-by-side comparison:

Feature Traditional Software AI Agent
Decision Making Follows fixed if/else rules Reasons dynamically using AI models
Adaptability Requires code changes to handle new cases Adapts to new situations autonomously
Input Handling Expects structured, predictable input Handles ambiguous, unstructured input
Goal Orientation Executes specific functions Pursues high-level goals flexibly
Error Recovery Fails or crashes on unexpected input Attempts to recover or ask for clarification

How Do AI Agents Work?

At a high level, an AI agent operates in a continuous loop. Understanding this loop is the key to understanding agent architecture:

  1. Perceive: The agent receives input from its environment (user messages, sensor readings, API data, etc.).
  2. Think: The agent processes this input using an AI model (like a large language model), reasoning about what to do next.
  3. Act: The agent takes an action — it might call a tool, send a message, update a database, or ask a follow-up question.
  4. Observe: The agent observes the result of its action and feeds that information back into the loop.
  5. Repeat: The cycle continues until the agent's goal is achieved or it determines it needs human input.
Pro Tip: This "perceive → think → act → observe" loop is sometimes called the OODA loop (Observe, Orient, Decide, Act) in military and AI contexts. You'll see variations of this pattern in nearly every agent framework.

A Simple Python Example

Let's look at a minimal example of an AI agent loop in Python. Don't worry if every detail isn't clear yet — we'll build on this throughout the course:

import openai

class SimpleAgent:
    def __init__(self, system_prompt):
        self.system_prompt = system_prompt
        self.conversation_history = []

    def perceive(self, user_input):
        """Receive input from the user."""
        self.conversation_history.append({
            "role": "user",
            "content": user_input
        })

    def think(self):
        """Use an AI model to reason about the next response."""
        messages = [
            {"role": "system", "content": self.system_prompt},
            *self.conversation_history
        ]
        response = openai.chat.completions.create(
            model="gpt-4",
            messages=messages
        )
        return response.choices[0].message.content

    def act(self, response):
        """Output the agent's response."""
        self.conversation_history.append({
            "role": "assistant",
            "content": response
        })
        return response

    def run(self, user_input):
        """Run one full loop: perceive → think → act."""
        self.perceive(user_input)
        response = self.think()
        return self.act(response)

# Create and run the agent
agent = SimpleAgent(
    system_prompt="You are a helpful assistant that explains AI concepts simply."
)

result = agent.run("What is an AI agent?")
print(result)

In this example, you can see the core loop in action. The run() method orchestrates the entire perceive → think → act cycle. The agent maintains a conversation history, which serves as its short-term memory.

Types of AI Agents

Not all AI agents are created equal. They range from very simple to incredibly complex. Here are the main categories you'll encounter:

1. Simple Reflex Agents

These agents act based solely on the current input, with no memory of past interactions. They follow simple "if this, then that" rules. Think of a thermostat: if the temperature drops below a threshold, it turns on the heat.

2. Model-Based Agents

These agents maintain an internal model of the world. They track state over time and use that context to make better decisions. Our Python example above is a model-based agent because it keeps a conversation history.

3. Goal-Based Agents

These agents have explicit goals and plan their actions to achieve them. They don't just react — they think ahead. For example, a goal-based travel agent might plan an entire itinerary to satisfy a user's vacation preferences.

4. Utility-Based Agents

These agents go a step further by assigning values to different outcomes. They don't just ask "did I reach the goal?" — they ask "how well did I reach the goal?" This allows them to choose the best path among many possible ones.

5. Learning Agents

These agents improve over time. They learn from feedback, adjust their strategies, and get better at achieving their goals. Most modern AI agents incorporate some form of learning.

Important: In practice, most real-world AI agents combine elements from multiple categories. A sophisticated agent might be goal-based, utility-driven, and capable of learning. Don't get too caught up in rigidly classifying agents — focus on understanding the concepts.

Real-World Examples of AI Agents

AI agents are already all around us. Here are some examples you may have encountered:

  • Customer Service Chatbots: Agents that handle support tickets, answer questions, and escalate complex issues to humans.
  • Autonomous Vehicles: Self-driving cars that perceive road conditions, make driving decisions, and navigate to destinations.
  • Personal Assistants: Tools like Siri, Alexa, and Google Assistant that understand natural language and perform tasks on your behalf.
  • Code Generation Agents: AI systems that can write, review, and debug code based on natural language descriptions.
  • Research Agents: Systems that autonomously search the web, synthesize information, and produce reports on complex topics.

Exercise: Add a Tool to Your Agent

Modify the SimpleAgent class to add a calculator tool. The agent should be able to detect when the user asks a math question and use Python's eval() function (safely!) to compute the answer.

Specifically:

  1. Add a tools dictionary to the agent's __init__ method with a "calculator" entry.
  2. Modify the think() method to check if the user's input contains a math expression.
  3. If it does, use the calculator tool to compute the result before generating a response.
  4. Test your agent with the input: "What is 42 * 17?"
import openai
import re

class SimpleAgentWithTools:
    def __init__(self, system_prompt):
        self.system_prompt = system_prompt
        self.conversation_history = []
        self.tools = {
            "calculator": self._calculator
        }

    def _calculator(self, expression):
        """Safely evaluate a mathematical expression."""
        # Only allow numbers and basic math operators
        if not re.match(r'^[\d\s\+\-\*\/\(\)\.]+$', expression):
            return "Sorry, I can only do basic math."
        try:
            result = eval(expression)
            return str(result)
        except Exception as e:
            return f"Error calculating: {e}"

    def perceive(self, user_input):
        self.conversation_history.append({
            "role": "user",
            "content": user_input
        })

    def think(self):
        # Check if the last user message is a math question
        last_input = self.conversation_history[-1]["content"]

        # Try to extract a math expression
        math_match = re.search(r'[\d\s\+\-\*\/\(\)\.]+', last_input)
        if math_match:
            expression = math_match.group().strip()
            if any(op in expression for op in ['+', '-', '*', '/']):
                tool_result = self.tools["calculator"](expression)
                return f"The answer is {tool_result}."

        # Otherwise, use the AI model
        messages = [
            {"role": "system", "content": self.system_prompt},
            *self.conversation_history
        ]
        response = openai.chat.completions.create(
            model="gpt-4",
            messages=messages
        )
        return response.choices[0].message.content

    def act(self, response):
        self.conversation_history.append({
            "role": "assistant",
            "content": response
        })
        return response

    def run(self, user_input):
        self.perceive(user_input)
        response = self.think()
        return self.act(response)

# Test it!
agent = SimpleAgentWithTools(
    system_prompt="You are a helpful assistant."
)
result = agent.run("What is 42 * 17?")
print(result)  # Output: The answer is 714.

Notice how the agent now has a tool — a capability beyond just generating text. This is a crucial step toward building truly useful agents. In later lessons, we'll learn how to give agents many more tools and how to let the AI model decide which tool to use.

Key Takeaways

  • An AI agent is an autonomous system that perceives, reasons, acts, and learns to achieve goals.
  • The core agent loop is: Perceive → Think → Act → Observe → Repeat.
  • AI agents differ from traditional software in their ability to handle ambiguity, adapt to new situations, and make dynamic decisions.
  • Agents range from simple reflex agents to sophisticated learning agents, and most real-world agents combine multiple approaches.
  • Adding tools to an agent dramatically expands its capabilities beyond text generation.
  • Memory (like conversation history) is what gives agents context and enables multi-turn interactions.
