Web Search & Scraping Tools

Learn about web search & scraping tools.

What Are Web Tools in AI Agents?

As an AI agent, your ability to interact with the world goes far beyond just answering questions from your training data. In this lesson, you'll learn how to equip your agent with the power to search the web and scrape information from websites — two essential skills that transform a static language model into a dynamic, real-time information gatherer.

Web search and scraping tools allow your AI agent to:

  • Retrieve up-to-date information that wasn't in the training data
  • Verify facts and cross-reference sources
  • Extract structured data from unstructured web pages
  • Automate research tasks and data collection
Why this matters: Without web tools, your AI agent is limited to knowledge frozen at training time. With these tools, it becomes a living, breathing research assistant that can access the latest information on demand.

Understanding Web Search APIs

Web search APIs allow your AI agent to programmatically query search engines and retrieve results. Instead of a human typing into Google, your agent formulates queries and processes the results automatically.

How Web Search Works in an Agent

The typical flow for web search in an AI agent looks like this:

  1. The agent identifies an information gap or receives a user query
  2. It formulates an appropriate search query
  3. It calls a search API with that query
  4. It parses the returned results (titles, snippets, URLs)
  5. It decides whether to present results, refine the query, or scrape a specific page

Example: Using a Search API with Python

Below is a practical example of how you might integrate a web search tool into your agent. We'll use a simplified approach that demonstrates the core concept:

import requests
import json

def web_search(query, api_key, num_results=5):
    """
    Search the web using a search API.
    Returns a list of result dictionaries with title, snippet, and url.
    """
    endpoint = "https://api.example-search.com/v1/search"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    }
    params = {
        "q": query,
        "num": num_results
    }

    response = requests.get(endpoint, headers=headers, params=params)
    response.raise_for_status()

    results = response.json().get("results", [])
    return [
        {
            "title": r.get("title", ""),
            "snippet": r.get("snippet", ""),
            "url": r.get("url", "")
        }
        for r in results
    ]

# Example usage in an agent context
def agent_search(user_question):
    search_results = web_search(user_question, api_key="your-api-key")

    print(f"Found {len(search_results)} results:")
    for i, result in enumerate(search_results, 1):
        print(f"\n--- Result {i} ---")
        print(f"Title: {result['title']}")
        print(f"Snippet: {result['snippet']}")
        print(f"URL: {result['url']}")

    return search_results

# Try it out
agent_search("latest developments in quantum computing 2024")
Pro Tip: Popular search APIs include SerpAPI, Bing Search API, and Google Custom Search API. Each has different pricing tiers and rate limits. Always check the documentation for authentication requirements and query formatting.

Web Scraping Fundamentals

While search APIs give you links and snippets, web scraping is the process of extracting full content from specific web pages. This is where your agent reads entire articles, product pages, or data tables to gather detailed information.

Key Concepts in Web Scraping

Before writing scraping code, you need to understand a few important concepts:

  • HTML Parsing: Web pages are written in HTML. Your scraper reads this structure to find the data you need.
  • CSS Selectors: These are patterns that target specific elements on a page (like h1.title or div.content p).
  • Robots.txt: A file on most websites that tells bots which pages they are allowed to scrape. Always respect it.
  • Rate Limiting: Sending too many requests too fast can get your IP blocked. Be polite and add delays.

Basic Scraping with Python

Here's a complete example of scraping a web page using the popular requests and BeautifulSoup libraries:

import requests
from bs4 import BeautifulSoup
import time

def scrape_page(url):
    """
    Scrape a web page and extract key information.
    Returns a dictionary with extracted data.
    """
    # Set a user agent to identify your bot
    headers = {
        "User-Agent": "AI-Agent-Tutorial-Bot/1.0"
    }

    # Make the request
    response = requests.get(url, headers=headers)
    response.raise_for_status()

    # Parse the HTML
    soup = BeautifulSoup(response.text, "html.parser")

    # Extract information using CSS selectors
    data = {
        "title": soup.select_one("h1").get_text(strip=True) if soup.select_one("h1") else "N/A",
        "meta_description": "",
        "headings": [],
        "paragraphs": [],
        "links": []
    }

    # Get meta description
    meta = soup.select_one('meta[name="description"]')
    if meta:
        data["meta_description"] = meta.get("content", "")

    # Get all h2 headings
    for heading in soup.select("h2"):
        text = heading.get_text(strip=True)
        if text:
            data["headings"].append(text)

    # Get first few paragraphs
    for p in soup.select("p")[:5]:
        text = p.get_text(strip=True)
        if text and len(text) > 20:
            data["paragraphs"].append(text)

    # Get all links
    for link in soup.select("a[href]")[:10]:
        data["links"].append({
            "text": link.get_text(strip=True),
            "href": link.get("href", "")
        })

    return data

# Example usage
url = "https://example.com/article"
result = scrape_page(url)

print(f"Title: {result['title']}")
print(f"Description: {result['meta_description']}")
print(f"\nHeadings found:")
for h in result["headings"]:
    print(f"  - {h}")
print(f"\nFirst paragraph:\n{result['paragraphs'][0] if result['paragraphs'] else 'None'}")
Important: Always check a website's robots.txt file and Terms of Service before scraping. Add delays between requests using time.sleep(1) to avoid overwhelming servers. Never scrape personal or sensitive data without permission.

Search vs. Scraping: When to Use Each

Understanding when to use search versus scraping is crucial for building effective agents. Here's a comparison:

Feature Web Search API Web Scraping
Primary Use Finding relevant pages and URLs Extracting detailed content from specific pages
Input A search query string A specific URL
Output List of results with titles, snippets, URLs Full HTML content, parsed text, structured data
Cost Usually paid per query Free (but requires infrastructure)
Speed Fast — returns summaries Slower — must download full pages
Reliability High — structured API responses Lower — page structures change, may break
Best For Discovery, finding sources, trending topics Deep content extraction, data tables, full articles

Building a Combined Search-and-Scrape Agent Tool

The real power comes from combining both tools. Your agent can search for relevant pages, then scrape the most promising ones for detailed information. Here's how you might build this as a reusable agent tool:

import requests
from bs4 import BeautifulSoup
import time

class WebSearchTool:
    """Tool for searching the web."""

    def __init__(self, api_key):
        self.api_key = api_key
        self.endpoint = "https://api.example-search.com/v1/search"

    def search(self, query, num_results=5):
        headers = {"Authorization": f"Bearer {self.api_key}"}
        params = {"q": query, "num": num_results}
        response = requests.get(self.endpoint, headers=headers, params=params)
        response.raise_for_status()
        return response.json().get("results", [])


class WebScrapeTool:
    """Tool for scraping web pages."""

    def __init__(self, delay=1):
        self.delay = delay
        self.headers = {"User-Agent": "AI-Agent-Tutorial-Bot/1.0"}

    def scrape(self, url):
        time.sleep(self.delay)  # Be polite
        response = requests.get(url, headers=self.headers)
        response.raise_for_status()
        soup = BeautifulSoup(response.text, "html.parser")

        # Remove script and style elements
        for element in soup(["script", "style", "nav", "footer", "header"]):
            element.decompose()

        # Get clean text
        text = soup.get_text(separator="\n", strip=True)
        lines = [line for line in text.splitlines() if line.strip()]
        return "\n".join(lines[:100])  # First 100 meaningful lines


class ResearchAgent:
    """An agent that combines search and scraping."""

    def __init__(self, search_api_key):
        self.search_tool = WebSearchTool(api_key=search_api_key)
        self.scrape_tool = WebScrapeTool(delay=1)

    def research(self, question):
        """Research a question by searching then scraping top results."""
        print(f"🔍 Searching for: {question}")
        search_results = self.search_tool.search(question, num_results=3)

        if not search_results:
            print("No results found.")
            return None

        # Scrape the top result for detailed content
        top_url = search_results[0].get("url", "")
        print(f"📄 Scraping: {top_url}")
        content = self.scrape_tool.scrape(top_url)

        return {
            "question": question,
            "search_results": search_results,
            "detailed_content": content[:2000]  # First 2000 chars
        }

# Usage
# agent = ResearchAgent(search_api_key="your-key-here")
# result = agent.research("What are the latest breakthroughs in fusion energy?")
# print(result["detailed_content"])
Design Pattern: Notice how we separate the search tool, scrape tool, and agent into distinct classes. This makes each component testable and replaceable. You could swap out the search API or scraping library without changing the agent logic.

Handling Common Challenges

When building web tools for AI agents, you'll encounter several common challenges. Here's how to handle them:

1. Rate Limiting and Errors

import time
from requests.exceptions import HTTPError, ConnectionError

def safe_request(url, max_retries=3, delay=2):
    """Make a web request with retry logic."""
    for attempt in range(max_retries):
        try:
            response = requests.get(url, timeout=10)
            response.raise_for_status()
            return response
        except HTTPError as e:
            if response.status_code == 429:  # Rate limited
                wait_time = delay * (attempt + 1)
                print(f"Rate limited. Waiting {wait_time}s...")
                time.sleep(wait_time)
            else:
                print(f"HTTP Error: {e}")
                return None
        except ConnectionError:
            print(f"Connection failed (attempt {attempt + 1}/{max_retries})")
            time.sleep(delay)
    return None

2. Dynamic Content (JavaScript-Rendered Pages)

Some websites load content dynamically using JavaScript. For these, requests and BeautifulSoup won't be enough. You'll need a headless browser:

from selenium import webdriver
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

def scrape_dynamic_page(url):
    """Scrape a page that uses JavaScript to load content."""
    options = Options()
    options.add_argument("--headless")  # Run without opening a window
    options.add_argument("--no-sandbox")
    options.add_argument("--disable-dev-shm-usage")

    driver = webdriver.Chrome(options=options)

    try:
        driver.get(url)

        # Wait for specific content to load
        WebDriverWait(driver, 10).until(
            EC.presence_of_element_located((By.CSS_SELECTOR, "main article"))
        )

        # Extract content once loaded
        title = driver.title
        body = driver.find_element(By.CSS_SELECTOR, "main").text

        return {"title": title, "content": body}
    finally:
        driver.quit()
Tip: Use requests + BeautifulSoup as your default approach. Only switch to Selenium or Playwright when you encounter pages that load content dynamically with JavaScript. Headless browsers are significantly slower and more resource-intensive.

def agent_lookup(question, api_key):
    """
    Search the web for a question and scrape the top result.
    
    Args:
        question: The user's question string
        api_key: API key for the search service
    
    Returns:
        Dictionary with question, result info, and content preview

    # Initialize tools
    search_tool = WebSearchTool(api_key=api_key)
    scrape_tool = WebScrapeTool(delay=1)

    try:
        content = scrape_tool.scrape(top_url)
        preview = content[:500]
    except Exception as e:
        preview = f"Could not scrape content: {str(e)}"

    return {
        "question": question,
        "top_result_title": top_title,
        "top_result_url": top_url,
        "content_preview": preview

Ethical Considerations

With great power comes great responsibility. When building web tools for your AI agent, keep these ethical guidelines in mind:

  • Respect robots.txt: Always check and follow the rules set by website owners.
  • Rate limit your requests: Don't flood servers. Add delays between requests.
  • Identify your bot: Use a descriptive User-Agent string so site owners can contact you.
  • Don't scrape personal data: Avoid collecting personal information without consent.
  • Cache results: Store results locally to avoid repeated requests for the same content.
  • Follow Terms of Service: Read and comply with each website's ToS.
Warning: Violating a website's Terms of Service or scraping personal data can have legal consequences. When in doubt, use official APIs instead of scraping, and always consult legal guidance for production applications.

Key Takeaways

  • Web search APIs help your agent discover relevant pages and sources by querying search engines programmatically.
  • Web scraping extracts detailed content from specific pages, turning unstructured HTML into usable data.
  • Use search for discovery and scraping for deep content extraction — they complement each other perfectly.
  • BeautifulSoup + requests is the go-to combination for static pages; use Selenium/Playwright for JavaScript-rendered content.
  • Always handle errors gracefully with retry logic, rate limiting, and proper exception handling.
  • Respect robots.txt and website Terms of Service — ethical scraping is sustainable scraping.
  • Separate your tools into classes (search tool, scrape tool, agent) for clean, maintainable, and testable code.
  • Cache and delay your requests to minimize server load and avoid getting blocked.
