The Agent Loop with Tools

Welcome to Day 4, Lesson 3! In this lesson, we'll explore how AI agents use tools within a continuous loop to solve complex problems. You'll learn the core mechanics behind agent behavior and see real Python code that brings these concepts to life.

What Is an Agent Loop?

An agent loop is the repeating cycle an AI agent follows to accomplish tasks. Instead of giving a single response, the agent:

  1. Receives a goal or question
  2. Decides what action to take
  3. Uses a tool if needed
  4. Observes the result
  5. Repeats until the task is complete

This loop allows agents to handle multi-step problems, like searching the web, calculating math, or calling APIs.

💡 Did you know? The agent loop is inspired by how humans solve problems: we plan, act, observe, and adjust—over and over.

Why Tools Matter

Without tools, an AI agent can only generate text. With tools, it can:

  • Search the internet
  • Run code
  • Access databases
  • Send emails or messages

Each tool extends the agent’s capabilities beyond language generation.

Common Tool Types

Tool Type Purpose Example
Search Find real-time info Google Search API
Calculator Perform math Python eval()
Code Interpreter Run scripts Jupyter kernel
API Caller Interact with services Weather API

Building a Simple Agent Loop in Python

Let’s build a basic agent that uses a calculator tool to solve math problems.

def calculator(expression):
    try:
        return str(eval(expression))
    except:
        return "Error: Invalid expression"

def agent_loop(question):
    print(f"Question: {question}")
    # Step 1: Decide if we need the calculator
    if "calculate" in question.lower() or any(op in question for op in ['+', '-', '*', '/']):
        # Extract expression (simplified)
        expr = question.split("calculate ")[-1] if "calculate" in question else question
        result = calculator(expr)
        print(f"Using calculator: {expr} = {result}")
        return result
    else:
        return "I can only help with math calculations."

# Test it
print(agent_loop("What is 12 * 7 + 3?"))
✅ Tip: Always validate user input before using eval() in production code. This example is simplified for learning.

Adding Multiple Tools

Real agents often choose between several tools. Here’s how we can expand our agent:

def search_web(query):
    # Simulated search
    return f"Search results for '{query}': [Result 1, Result 2]"

def get_weather(city):
    # Simulated weather
    return f"Weather in {city}: Sunny, 72°F"

def agent_with_tools(question):
    if "weather" in question.lower():
        city = question.split("in ")[-1].strip("?")
        return get_weather(city)
    elif "search" in question.lower() or "find" in question.lower():
        query = question.split("search for ")[-1] if "search for" in question else question
        return search_web(query)
    else:
        return "I don't have a tool for that."

# Try it
print(agent_with_tools("What's the weather in Paris?"))
print(agent_with_tools("Search for AI agents"))
⚠️ Warning: Never expose raw eval() to untrusted users. Use safe parsing libraries like ast.literal_eval or math-specific parsers instead.

Exercise: Build Your Own Tool

Exercise

Add a new tool to the agent that converts temperatures from Fahrenheit to Celsius. The formula is: C = (F - 32) * 5/9.

Modify the agent_with_tools function to handle questions like: "Convert 98.6°F to Celsius".

def fahrenheit_to_celsius(f):
    return (f - 32) * 5 / 9

def agent_with_tools(question):
    if "convert" in question.lower() and "fahrenheit" in question.lower():
        # Extract number (simplified)
        parts = question.split()
        for part in parts:
            try:
                f = float(part)
                c = fahrenheit_to_celsius(f)
                return f"{f}°F is {c:.1f}°C"
            except ValueError:
                continue
        return "Could not find temperature value."
    elif "weather" in question.lower():
        city = question.split("in ")[-1].strip("?")
        return get_weather(city)
    elif "search" in question.lower() or "find" in question.lower():
        query = question.split("search for ")[-1] if "search for" in question else question
        return search_web(query)
    else:
        return "I don't have a tool for that."

# Test
print(agent_with_tools("Convert 98.6°F to Celsius"))

Key Takeaways

  • An agent loop is a repeating cycle of thinking, acting, and observing.
  • Tools give agents real-world capabilities like searching, calculating, or calling APIs.
  • You can build simple agents in Python using conditional logic and function calls.
  • Always validate inputs and avoid unsafe functions like eval() in real applications.
  • Agents become more powerful as you add more tools and better decision logic.
