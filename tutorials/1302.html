Chroma DB Setup

Learn about chroma db setup.

What Is Chroma DB?

Chroma DB is an open-source vector database designed specifically for storing, querying, and managing embeddings — the numerical representations of text, images, and other data that AI models understand. Unlike traditional databases that store rows and columns of structured data, Chroma DB stores vectors (arrays of numbers) and lets you search them by similarity. This makes it a critical building block for Retrieval-Augmented Generation (RAG), semantic search, and memory systems in AI agents.

Think of it this way: when your AI agent needs to "remember" past conversations, look up relevant documents, or find similar examples from a knowledge base, Chroma DB is the engine that makes that fast similarity search possible.

💡 Why "vector" database? A vector is just a list of numbers that captures the meaning of data. Chroma DB lets you find items whose vectors are closest to a query vector — meaning it finds things that are semantically similar, not just textually identical.

Installing Chroma DB

Getting started with Chroma DB is straightforward. You can install it via pip, Python's package manager. We'll also install the openai library since we'll use OpenAI's embedding model to convert text into vectors.

# Install Chroma DB and OpenAI SDK
pip install chromadb openai

Once installed, you can import and use Chroma DB directly in your Python scripts or Jupyter notebooks — no separate server is required for the default in-memory or persistent modes.

🚀 Tip: Chroma DB supports three modes:
  • In-memory — fast, but data is lost when the script ends
  • Persistent (local) — saves to disk, great for development
  • Client/Server — runs as a separate service, ideal for production
For this lesson, we'll use persistent mode so your data survives between sessions.

Creating Your First Collection

In Chroma DB, data is organized into collections. A collection is like a table in a traditional database — it holds a set of related documents along with their embeddings and optional metadata.

Step 1: Initialize the Persistent Client

import chromadb

# Create a persistent client that saves data to a local folder
client = chromadb.PersistentClient(path="./chroma_storage")

print("Chroma DB client initialized!")

Step 2: Create a Collection

# Create a collection for our AI agent's knowledge base
collection = client.get_or_create_collection(
    name="agent_knowledge_base",
    metadata={"hnsw:space": "cosine"}  # Use cosine similarity for search
)

print(f"Collection '{collection.name}' is ready!")
print(f"Current document count: {collection.count()}")
⚠️ Note: Always use get_or_create_collection() instead of create_collection() unless you specifically want to throw an error if the collection already exists. Using create_collection() on an existing name will raise an exception.

Adding Documents with Embeddings

Now let's add some documents to our collection. Chroma DB can automatically generate embeddings for you using built-in models, or you can provide your own. We'll show both approaches.

Approach 1: Auto-Embedding (Easiest)

# Chroma DB will automatically embed these documents
# using its default embedding function

documents = [
    "Python is a high-level programming language known for its readability.",
    "Machine learning is a subset of artificial intelligence.",
    "Chroma DB is a vector database for AI applications.",
    "Retrieval-Augmented Generation combines search with language models.",
    "An AI agent is a system that perceives its environment and takes actions."
]

ids = ["doc_1", "doc_2", "doc_3", "doc_4", "doc_5"]

collection.add(
    documents=documents,
    ids=ids
)

print(f"Added {collection.count()} documents to the collection!")

Approach 2: Custom Embeddings with OpenAI

For production-quality embeddings, you'll want to use a dedicated embedding model. Here's how to generate embeddings with OpenAI and store them in Chroma DB:

import openai

# Set your API key (use environment variables in production!)
openai.api_key = "your-api-key-here"

def get_embedding(text):
    """Generate an embedding for a given text using OpenAI."""
    response = openai.Embedding.create(
        input=text,
        model="text-embedding-ada-002"
    )
    return response['data'][0]['embedding']

# Generate embeddings manually
custom_docs = [
    "Neural networks are inspired by biological neurons.",
    "Transformers revolutionized natural language processing."
]

custom_embeddings = [get_embedding(doc) for doc in custom_docs]
custom_ids = ["doc_6", "doc_7"]

collection.add(
    embeddings=custom_embeddings,
    documents=custom_docs,
    ids=custom_ids
)

print(f"Total documents now: {collection.count()}")

Querying Your Collection

The real power of Chroma DB comes from similarity search. You provide a query, and Chroma DB returns the most semantically similar documents.

Basic Similarity Search

# Search for documents similar to our query
results = collection.query(
    query_texts=["What is AI?"],
    n_results=3  # Return top 3 matches
)

print("Query: 'What is AI?'\n")
for i, (doc, distance) in enumerate(zip(
    results['documents'][0],
    results['distances'][0]
)):
    print(f"  Result {i+1} (distance: {distance:.4f}):")
    print(f"  {doc}\n")

Searching with Metadata Filters

You can also attach metadata to documents and filter your searches. This is incredibly useful for organizing an AI agent's knowledge base by topic, source, or date.

# Add documents with metadata
collection.add(
    documents=[
        "Supervised learning uses labeled training data.",
        "Unsupervised learning finds patterns in unlabeled data.",
        "Reinforcement learning uses rewards and penalties."
    ],
    ids=["doc_8", "doc_9", "doc_10"],
    metadatas=[
        {"category": "ml_type", "difficulty": "beginner"},
        {"category": "ml_type", "difficulty": "intermediate"},
        {"category": "ml_type", "difficulty": "advanced"}
    ]
)

# Query only beginner-level documents
filtered_results = collection.query(
    query_texts=["types of learning"],
    n_results=5,
    where={"difficulty": "beginner"}
)

print("Filtered results (beginner only):")
for doc in filtered_results['documents'][0]:
    print(f"  - {doc}")

Updating and Deleting Documents

Chroma DB supports full CRUD operations. Here's how to update and remove documents from your collection:

# Update a document (re-embeds and replaces)
collection.update(
    ids=["doc_1"],
    documents=["Python is a versatile, high-level programming language widely used in AI and web development."]
)

# Delete specific documents
collection.delete(ids=["doc_10"])

# Verify the changes
print(f"Document count after update and delete: {collection.count()}")
⚠️ Important: When you update a document, Chroma DB will re-embed it using the collection's embedding function. If you originally provided custom embeddings, you must provide them again during update, or the auto-embedding function will be used instead.

Chroma DB vs. Other Vector Databases

There are several vector databases available. Here's how Chroma DB compares to popular alternatives:

Feature Chroma DB Pinecone Weaviate FAISS
Open Source ✅ Yes ❌ Managed only ✅ Yes ✅ Yes
Self-Hosted ✅ Yes ❌ No ✅ Yes ✅ Yes
Ease of Setup ⭐⭐⭐⭐⭐ ⭐⭐⭐⭐ ⭐⭐⭐ ⭐⭐
Metadata Filtering ✅ Yes ✅ Yes ✅ Yes ❌ Limited
Best For Prototyping & small-medium apps Production at scale Enterprise search Research & large-scale search
🎯 Recommendation: For AI agent development, start with Chroma DB for its simplicity and zero-config setup. As your agent scales to production with millions of documents, consider migrating to Pinecone or Weaviate.

Putting It All Together: A Mini RAG Pipeline

Let's build a small but complete example that demonstrates how Chroma DB fits into a Retrieval-Augmented Generation pipeline for an AI agent:

import chromadb
import openai

# --- Setup ---
client = chromadb.PersistentClient(path="./chroma_storage")
collection = client.get_or_create_collection(
    name="agent_memory",
    metadata={"hnsw:space": "cosine"}
)

# --- Ingest Knowledge ---
knowledge = [
    "The capital of France is Paris.",
    "The speed of light is approximately 299,792 km/s.",
    "Python was created by Guido van Rossum in 1991.",
    "The Great Wall of China is over 13,000 miles long.",
    "Water boils at 100 degrees Celsius at sea level."
]

collection.add(
    documents=knowledge,
    ids=[f"fact_{i}" for i in range(len(knowledge))]
)

# --- Retrieve Relevant Context ---
def retrieve_context(query, n_results=2):
    results = collection.query(
        query_texts=[query],
        n_results=n_results
    )
    return results['documents'][0]

# --- Simulate RAG Response ---
user_question = "Who created Python?"
context = retrieve_context(user_question)

print(f"Question: {user_question}")
print(f"Retrieved context: {context}")
print(f"\n[In a real agent, this context would be sent to an LLM")
print(f"to generate a grounded, accurate response.]")
🧩 Exercise: Build a Document Search Tool

Create a Python script that:

  1. Initializes a persistent Chroma DB client at ./my_search_db
  2. Creates a collection called "articles"
  3. Adds at least 5 documents of your choice (e.g., facts about space, cooking recipes, or programming tips) with unique IDs and metadata including a "topic" field
  4. Performs a similarity search for a query of your choice
  5. Performs a filtered search that only returns documents from a specific topic
  6. Prints the results of both searches

Make sure to use metadata filtering in step 5!

import chromadb

# Step 1: Initialize persistent client
client = chromadb.PersistentClient(path="./my_search_db")

# Step 2: Create collection
collection = client.get_or_create_collection(
    name="articles",
    metadata={"hnsw:space": "cosine"}
)

# Step 3: Add documents with metadata
articles = [
    "Mars is called the Red Planet due to iron oxide on its surface.",
    "Jupiter is the largest planet in our solar system.",
    "Saturn's rings are made mostly of ice and rock particles.",
    "Venus rotates in the opposite direction to most planets.",
    "Neptune has the strongest winds in the solar system, reaching 1,200 mph."
]

collection.add(
    documents=articles,
    ids=["space_1", "space_2", "space_3", "space_4", "space_5"],
    metadatas=[
        {"topic": "planets", "source": "nasa"},
        {"topic": "planets", "source": "textbook"},
        {"topic": "planets", "source": "nasa"},
        {"topic": "planets", "source": "encyclopedia"},
        {"topic": "weather", "source": "nasa"}
    ]
)

# Step 4: Similarity search
print("=== Similarity Search ===")
results = collection.query(
    query_texts=["biggest planet"],
    n_results=3
)
for doc in results['documents'][0]:
    print(f"  - {doc}")

# Step 5: Filtered search (only NASA sources)
print("\n=== Filtered Search (NASA only) ===")
filtered = collection.query(
    query_texts=["planet facts"],
    n_results=5,
    where={"source": "nasa"}
)
for doc in filtered['documents'][0]:
    print(f"  - {doc}")

# Step 6: Done!
print(f"\nTotal documents in collection: {collection.count()}")

Key Takeaways

  • Chroma DB is an open-purpose vector database optimized for AI applications like RAG, semantic search, and agent memory.
  • Data is stored in collections, which hold documents, their embeddings, and optional metadata.
  • Chroma DB can auto-embed documents or accept custom embeddings from models like OpenAI's text-embedding-ada-002.
  • Use persistent mode (PersistentClient) to save your data to disk so it survives between sessions.
  • Similarity search finds the most relevant documents by comparing vector distances — use cosine similarity for text.
  • Metadata filtering lets you narrow search results by category, source, difficulty, or any custom field.
  • Chroma DB supports full CRUD operations: create, read (query), update, and delete documents.
  • For AI agents, Chroma DB serves as the memory and knowledge retrieval layer in a RAG pipeline.
