LangChain Memory

Learn about langchain memory.

What Is Memory in LangChain?

So far, every time you've sent a message to an AI, it started from scratch — it had no idea what you said before. That's like talking to someone with amnesia! Memory in LangChain solves this problem by giving your AI agent the ability to remember past interactions and use that context in future responses.

Think of memory as a notebook that your AI agent carries around. Every time you have a conversation, the agent writes down important details. The next time you ask a question, it flips through that notebook to remember what you talked about earlier.

Why does memory matter? Without memory, your AI agent treats every interaction as brand new. With memory, it can maintain context, personalize responses, and handle multi-turn conversations naturally — just like a human would.

Types of Memory in LangChain

LangChain offers several types of memory, each designed for different use cases. Let's explore the most important ones.

ConversationBufferMemory

This is the simplest and most commonly used memory type. It stores the entire conversation history as a list of messages. Every exchange between the user and the AI gets appended to this buffer.

from langchain.memory import ConversationBufferMemory
from langchain.chains import ConversationChain
from langchain.llms import OpenAI

# Create a memory instance
memory = ConversationBufferMemory()

# Build a conversation chain with memory
conversation = ConversationChain(
    llm=OpenAI(temperature=0),
    memory=memory,
    verbose=True
)

# First interaction
response1 = conversation.predict(input="Hi! My name is Alex.")
print(response1)

# Second interaction — the AI remembers your name!
response2 = conversation.predict(input="What's my name?")
print(response2)  # The AI will respond with "Alex!"

ConversationBufferWindowMemory

Sometimes you don't need to remember everything — just the last few exchanges. ConversationBufferWindowMemory keeps only the most recent k interactions, which helps manage token limits and keeps responses focused.

from langchain.memory import ConversationBufferWindowMemory

# Only remember the last 2 exchanges
memory = ConversationBufferWindowMemory(k=2)

conversation = ConversationChain(
    llm=OpenAI(temperature=0),
    memory=memory
)

conversation.predict(input="I love pizza.")
conversation.predict(input="I also love tacos.")
conversation.predict(input="And I enjoy sushi.")

# When asked about the first topic, it may have "forgotten" pizza
# because only the last 2 exchanges are stored
response = conversation.predict(input="What was the first food I mentioned?")
print(response)  # It might not remember pizza!

ConversationSummaryMemory

For very long conversations, storing every message becomes expensive. ConversationSummaryMemory uses the LLM itself to create a running summary of the conversation, condensing older exchanges into a brief overview.

from langchain.memory import ConversationSummaryMemory

memory = ConversationSummaryMemory(llm=OpenAI(temperature=0))

conversation = ConversationChain(
    llm=OpenAI(temperature=0),
    memory=memory
)

conversation.predict(input="I'm planning a trip to Japan next month.")
conversation.predict(input="I want to visit Tokyo and Kyoto.")
conversation.predict(input="I'm really excited about trying authentic ramen.")

# The memory now holds a summary of all three exchanges
# instead of storing each message individually
print(memory.load_memory_variables({}))

Comparing Memory Types

Memory Type What It Stores Best For Token Usage
ConversationBufferMemory Full conversation history Short conversations where full context matters High (grows over time)
ConversationBufferWindowMemory Last k exchanges only Conversations where recent context is most important Medium (fixed size)
ConversationSummaryMemory AI-generated summary of conversation Very long conversations Low (compressed)
ConversationSummaryBufferMemory Recent messages + summary of older ones Long conversations needing both detail and efficiency Medium-Low

How Memory Works Under the Hood

Understanding how memory integrates with LangChain chains will help you build more sophisticated agents. Here's what happens step by step:

  1. User sends a message — The input enters the chain.
  2. Memory is loaded — The chain retrieves the current memory contents and injects them into the prompt as context.
  3. LLM generates a response — The AI sees both the conversation history and the new input.
  4. Memory is updated — The new exchange (user input + AI response) is saved to memory.
  5. Response is returned — The user sees the AI's reply.
Pro tip: You can inspect what's stored in memory at any time using memory.load_memory_variables({}). This is incredibly useful for debugging — you can see exactly what context the AI is receiving.

Customizing Memory with Input and Output Keys

By default, LangChain assumes your conversation uses "input" and "output" as keys. But what if your application uses different field names? You can customize this:

from langchain.memory import ConversationBufferMemory

# Customize the keys to match your data structure
memory = ConversationBufferMemory(
    memory_key="chat_history",      # Key used in the prompt template
    input_key="user_message",       # Key for user input
    output_key="ai_response",       # Key for AI output
    return_messages=True            # Return as message objects instead of strings
)

# Now when you save context, use your custom keys
memory.save_context(
    {"user_message": "Hello, I'm Sarah."},
    {"ai_response": "Nice to meet you, Sarah!"}
)

# Check what's stored
print(memory.load_memory_variables({}))
# Output: {'chat_history': [HumanMessage(content="Hello, I'm Sarah."), AIMessage(content="Nice to meet you, Sarah!")]}

Memory with Chat Models

When working with chat models like GPT-4, you'll typically use ChatMessageHistory paired with a conversation chain. This approach gives you more control over the message format:

from langchain.memory import ChatMessageHistory
from langchain.schema import HumanMessage, AIMessage, SystemMessage

# Create a chat message history
history = ChatMessageHistory()

# Add messages manually
history.add_message(SystemMessage(content="You are a helpful coding assistant."))
history.add_user_message("How do I read a file in Python?")
history.add_ai_message("You can use the open() function: with open('file.txt', 'r') as f: content = f.read()")

# Add more exchanges
history.add_user_message("What about writing to a file?")
history.add_ai_message("Use 'w' mode: with open('file.txt', 'w') as f: f.write('Hello!')")

# See the full history
for message in history.messages:
    print(f"{message.type}: {message.content}")
Watch out for token limits! Every memory type adds tokens to your prompt. If your conversation grows too long, you'll hit the model's token limit and get errors. Always choose the right memory type for your use case, and consider setting a maximum buffer size.

Persistent Memory: Saving Conversations

By default, LangChain memory lives only in RAM — it disappears when your program restarts. For real applications, you'll want to persist memory to a database or file:

import json
from langchain.memory import ConversationBufferMemory

# Save memory to a file
def save_memory(memory, filepath="memory.json"):
    # Convert memory to a serializable format
    variables = memory.load_memory_variables({})
    with open(filepath, "w") as f:
        json.dump(variables, f, indent=2)
    print(f"Memory saved to {filepath}")

# Load memory from a file
def load_memory(filepath="memory.json"):
    with open(filepath, "r") as f:
        saved_data = json.load(f)
    
    memory = ConversationBufferMemory()
    # Restore the conversation from saved data
    for msg in saved_data.get("history", []):
        if msg["type"] == "human":
            memory.chat_memory.add_user_message(msg["content"])
        elif msg["type"] == "ai":
            memory.chat_memory.add_ai_message(msg["content"])
    return memory

# Usage
memory = ConversationBufferMemory()
memory.save_context({"input": "My favorite color is blue."}, {"output": "Got it! Blue is a great color."})

# Save it
save_memory(memory)

# Later... load it back
restored_memory = load_memory()
print(restored_memory.load_memory_variables({}))

Building a Memory-Enabled Agent

Now let's put it all together by building a simple agent that remembers user preferences across multiple interactions:

from langchain.memory import ConversationBufferMemory
from langchain.chains import ConversationChain
from langchain.chat_models import ChatOpenAI

class PersonalAssistant:
    def __init__(self):
        self.memory = ConversationBufferMemory(return_messages=True)
        self.chat = ChatOpenAI(temperature=0, model="gpt-4")
        self.conversation = ConversationChain(
            llm=self.chat,
            memory=self.memory,
            verbose=False
        )
    
    def chat_with_user(self, user_input):
        # Add a system instruction to encourage memory usage
        response = self.conversation.predict(input=user_input)
        return response
    
    def get_memory_summary(self):
        """See what the assistant remembers."""
        return self.memory.load_memory_variables({})

# Create the assistant
assistant = PersonalAssistant()

# Have a conversation
print(assistant.chat_with_user("Hi! I'm Jamie, and I'm learning Python."))
# → "Hello Jamie! That's great that you're learning Python..."

print(assistant.chat_with_user("I'm building a web scraper."))
# → "That sounds like a great project, Jamie! Web scraping is a useful Python skill..."

print(assistant.chat_with_user("What have we talked about so far?"))
# → "We talked about how you're Jamie, you're learning Python, and you're building a web scraper..."

# Inspect the memory
print(assistant.get_memory_summary())
Real-world applications: Memory-enabled agents power customer support bots that remember your issue history, tutoring systems that track your learning progress, and personal assistants that know your preferences — all without you having to repeat yourself.

Common Pitfalls and Best Practices

Here are the most common mistakes developers make with LangChain memory, and how to avoid them:

Pitfall 1: Memory Leaks in Production

Memory objects accumulate data indefinitely. In a production app with many users, this will consume massive amounts of RAM. Always implement cleanup strategies.

Pitfall 2: Sensitive Data in Memory

Memory stores everything — including potentially sensitive information like passwords, API keys, or personal data. Be intentional about what gets saved.

Pitfall 3: Not Testing Memory Behavior

Always test what your agent remembers and forgets. Use memory.load_memory_variables({}) to verify the context being passed to the LLM.

Best practices checklist:
  • Use ConversationBufferWindowMemory for most chatbot applications
  • Set a maximum memory size to prevent unbounded growth
  • Persist memory to a database for production applications
  • Clear memory between unrelated conversations
  • Log memory contents during development for debugging
  • Consider using ConversationSummaryMemory for conversations longer than 10-15 exchanges
Exercise: Build a Study Buddy with Memory

Create a StudyBuddy class that uses LangChain memory to help a student study for an exam. The buddy should:

  1. Remember the subject the student is studying
  2. Keep track of topics the student has already covered
  3. Remember topics the student finds difficult
  4. Suggest next topics based on what's been covered

Use ConversationBufferMemory as your starting point. Add a method called get_study_progress() that returns a summary of what the student has studied so far.

Bonus: Add a method to save the study session to a file and load it back later.

from langchain.memory import ConversationBufferMemory
from langchain.chains import ConversationChain
from langchain.chat_models import ChatOpenAI
import json

class StudyBuddy:
    def __init__(self, subject=None):
        self.subject = subject
        self.memory = ConversationBufferMemory(return_messages=True)
        self.chat = ChatOpenAI(temperature=0.7)
        self.conversation = ConversationChain(
            llm=self.chat,
            memory=self.memory
        )
        self.covered_topics = []
        self.difficult_topics = []
    
    def start_studying(self, subject):
        self.subject = subject
        prompt = f"I want to start studying {subject}. Help me create a study plan."
        response = self.conversation.predict(input=prompt)
        return response
    
    def study_topic(self, topic, difficulty="medium"):
        self.covered_topics.append(topic)
        
        if difficulty == "hard":
            self.difficult_topics.append(topic)
        
        prompt = f"I just studied '{topic}' in {self.subject}. "
        prompt += f"I found it {difficulty}. "
        prompt += f"So far I've covered: {', '.join(self.covered_topics)}. "
        prompt += "What should I study next?"
        
        response = self.conversation.predict(input=prompt)
        return response
    
    def get_study_progress(self):
        progress = f"Subject: {self.subject}\n"
        progress += f"Topics covered: {len(self.covered_topics)}\n"
        progress += f"Topics: {', '.join(self.covered_topics)}\n"
        if self.difficult_topics:
            progress += f"Topics to review: {', '.join(self.difficult_topics)}"
        return progress
    
    def save_session(self, filepath="study_session.json"):
        data = {
            "subject": self.subject,
            "covered_topics": self.covered_topics,
            "difficult_topics": self.difficult_topics,
            "memory": self.memory.load_memory_variables({})
        }
        with open(filepath, "w") as f:
            json.dump(data, f, indent=2, default=str)
        print(f"Study session saved to {filepath}")
    
    def load_session(self, filepath="study_session.json"):
        with open(filepath, "r") as f:
            data = json.load(f)
        self.subject = data["subject"]
        self.covered_topics = data["covered_topics"]
        self.difficult_topics = data["difficult_topics"]
        print(f"Study session loaded from {filepath}")

# Usage example
buddy = StudyBuddy()
print(buddy.start_studying("Machine Learning"))
print(buddy.study_topic("Linear Regression", difficulty="easy"))
print(buddy.study_topic("Neural Networks", difficulty="hard"))
print(buddy.get_study_progress())
buddy.save_session()

Key Takeaways

  • Memory gives AI agents context — Without it, every interaction starts from zero. With it, agents can maintain natural, flowing conversations.
  • Choose the right memory type for your use case — BufferMemory for short chats, WindowMemory for focused recent context, and SummaryMemory for long conversations.
  • Memory impacts your token usage — Every piece of stored memory gets sent to the LLM as part of the prompt. Monitor and manage memory size to stay within token limits and control costs.
  • Memory is customizable — You can change input/output keys, control message formats, and even create your own memory classes by extending LangChain's base memory class.
  • Persistence matters in production — In-memory storage works for development, but real applications need database-backed memory that survives restarts and scales across servers.
  • Always inspect what your memory contains — Use load_memory_variables() to debug and verify that your agent is receiving the right context at the right time.
  • Be mindful of sensitive data — Memory stores everything by default. Implement data retention policies and avoid storing passwords, API keys, or personal information in memory.
