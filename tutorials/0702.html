Linear Chains

Learn about linear chains.

What Are Linear Chains?

Linear chains are the simplest and most fundamental structure in AI agent design. They represent a sequence of steps that execute one after another, like a recipe where each step must be completed before moving to the next. This is the foundation upon which more complex agent architectures are built.

Think of a linear chain as a conveyor belt in a factory: items enter at one end, get processed at each station, and emerge fully assembled at the other end. Similarly, in a linear chain, data flows through a series of processing steps, with each step transforming the data before passing it to the next.

The Anatomy of a Linear Chain

Every linear chain consists of three core components:

  • Input: The initial data or query that starts the chain
  • Processing Steps: A sequence of operations that transform the data
  • Output: The final result produced by the last step
💡 Key Concept: Linear chains are deterministic. Given the same input, they will always produce the same output. This predictability makes them ideal for tasks where consistency is crucial, like data validation or report generation.

Simple Linear Chain Example

Let's look at a basic example where we process user input through a series of text transformations:

# A simple linear chain for text processing

def step_1_clean_text(text):
    """Step 1: Remove extra whitespace"""
    return ' '.join(text.split())

def step_2_lowercase(text):
    """Step 2: Convert to lowercase"""
    return text.lower()

def step_3_remove_punctuation(text):
    """Step 3: Remove punctuation"""
    import string
    return text.translate(str.maketrans('', '', string.punctuation))

def step_4_extract_keywords(text):
    """Step 4: Extract key terms"""
    common_words = {'the', 'a', 'an', 'is', 'are', 'in', 'on', 'at', 'to', 'for'}
    words = text.split()
    return [word for word in words if word not in common_words]

# The linear chain execution
def run_linear_chain(input_text):
    result = step_1_clean_text(input_text)
    result = step_2_lowercase(result)
    result = step_3_remove_punctuation(result)
    result = step_4_extract_keywords(result)
    return result

# Example usage
user_input = "  The AI Agent is Processing Data!!  "
output = run_linear_chain(user_input)
print(output)
# Output: ['ai', 'agent', 'processing', 'data']

Why Use Linear Chains?

Linear chains offer several advantages for AI agent development:

  1. Simplicity: Easy to understand, implement, and debug
  2. Predictability: Consistent behavior makes testing straightforward
  3. Modularity: Each step can be developed and tested independently
  4. Reusability: Individual steps can be reused in different chains

Common Use Cases

Use Case Description Example Steps
Data Preprocessing Cleaning and preparing data for analysis Clean → Normalize → Validate → Transform
Content Generation Creating structured content Research → Outline → Draft → Review
Query Processing Answering user questions Parse → Search → Synthesize → Format
Report Generation Automated report creation Collect → Analyze → Visualize → Export
💡 Pro Tip: Start every new AI agent project with a linear chain. Once that works perfectly, you can add complexity like branching or looping if needed. Premature optimization is the enemy of clean code!

Building Robust Linear Chains

As your chains grow more complex, you'll need strategies to handle errors and ensure reliability. Here's how to make your linear chains production-ready:

Error Handling

Always anticipate what could go wrong at each step. A failed step shouldn't crash the entire chain:

# Robust linear chain with error handling

def safe_execute(func, input_data, step_name):
    """Execute a step with error handling"""
    try:
        result = func(input_data)
        print(f"✅ {step_name} completed successfully")
        return result
    except Exception as e:
        print(f"❌ {step_name} failed: {str(e)}")
        return None  # or return a default value

def run_robust_chain(input_data):
    steps = [
        (step_1_clean_text, "Text Cleaning"),
        (step_2_lowercase, "Lowercase Conversion"),
        (step_3_remove_punctuation, "Punctuation Removal"),
        (step_4_extract_keywords, "Keyword Extraction")
    ]
    
    current_data = input_data
    
    for func, name in steps:
        current_data = safe_execute(func, current_data, name)
        if current_data is None:
            print(f"Chain stopped at: {name}")
            return None
    
    return current_data

Logging and Monitoring

In production, you need visibility into what your chain is doing:

# Linear chain with logging

import logging
import time

# Setup logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger("LinearChain")

def logged_chain(input_data):
    steps = [
        ("Clean Text", step_1_clean_text),
        ("Lowercase", step_2_lowercase),
        ("Remove Punctuation", step_3_remove_punctuation),
        ("Extract Keywords", step_4_extract_keywords)
    ]
    
    current = input_data
    start_time = time.time()
    
    logger.info(f"Chain started with input: '{input_data[:50]}...'")
    
    for step_name, func in steps:
        step_start = time.time()
        current = func(current)
        step_duration = time.time() - step_start
        logger.info(f"{step_name}: {step_duration:.3f}s")
    
    total_duration = time.time() - start_time
    logger.info(f"Chain completed in {total_duration:.3f}s")
    
    return current
⚠️ Warning: Linear chains can become unwieldy if they grow too long. If you find yourself with more than 10-15 steps, consider breaking the chain into smaller sub-chains or using a different architecture like DAGs (Directed Acyclic Graphs) which we'll cover later.

Testing Your Linear Chains

Testing is crucial for reliable AI agents. Here's how to test linear chains effectively:

Unit Testing Individual Steps

# Unit tests for individual chain steps

import unittest

class TestLinearChainSteps(unittest.TestCase):
    
    def test_step_1_clean_text(self):
        input_text = "  too   many   spaces  "
        expected = "too many spaces"
        result = step_1_clean_text(input_text)
        self.assertEqual(result, expected)
    
    def test_step_2_lowercase(self):
        input_text = "UPPERCASE TEXT"
        expected = "uppercase text"
        result = step_2_lowercase(input_text)
        self.assertEqual(result, expected)
    
    def test_step_3_remove_punctuation(self):
        input_text = "Hello, World! How are you?"
        expected = "Hello World How are you"
        result = step_3_remove_punctuation(input_text)
        self.assertEqual(result, expected)
    
    def test_step_4_extract_keywords(self):
        input_text = "the ai agent is processing data"
        expected = ['ai', 'agent', 'processing', 'data']
        result = step_4_extract_keywords(input_text)
        self.assertEqual(result, expected)

# Run the tests
if __name__ == '__main__':
    unittest.main()

Integration Testing the Full Chain

# Integration test for the full chain

class TestLinearChainIntegration(unittest.TestCase):

        self.assertEqual(result, expected)
Exercise: Build a Linear Chain for Email Processing

Create a linear chain that processes raw email content into a structured summary. Your chain should perform these steps:

  1. Remove HTML tags (simulate with regex)
  2. Extract the email body (remove headers)
  3. Clean and normalize the text
  4. Extract key action items (lines starting with "Action:", "TODO:", or "Please")
  5. Generate a summary dictionary with: sender, subject, action_items, and word_count

Test your chain with this sample email:

From: john@example.com
Subject: Project Update & Next Steps

<html><body>
Hi Team,

Here's the project update:

Action: Review the design document by Friday
TODO: Schedule client meeting
Please send feedback by EOD

The project is on track.
</body></html>
import re

def step_1_remove_html(text):
    """Remove HTML tags"""
    clean = re.sub('<.*?>', '', text)
    return clean.strip()

def step_2_extract_body(text):
    """Extract body after subject line"""
    lines = text.split('\n')
    body_start = 0
    for i, line in enumerate(lines):
        if line.startswith('Subject:'):
            body_start = i + 2  # Skip subject line and blank line
            break
    return '\n'.join(lines[body_start:])

def step_3_clean_text(text):
    """Clean and normalize text"""
    text = ' '.join(text.split())  # Remove extra whitespace
    return text.strip()

def step_4_extract_actions(text):
    """Extract action items"""
    lines = text.split('\n')
    actions = []
    for line in lines:
        line = line.strip()
        if line.startswith(('Action:', 'TODO:', 'Please')):
            actions.append(line)
    return actions

def step_5_generate_summary(text, actions):
    """Generate structured summary"""
    word_count = len(text.split())
    return {
        'sender': 'john@example.com',
        'subject': 'Project Update & Next Steps',
        'action_items': actions,
        'word_count': word_count
    }

def process_email(raw_email):
    """Linear chain for email processing"""
    result = step_1_remove_html(raw_email)
    result = step_2_extract_body(result)
    result = step_3_clean_text(result)
    actions = step_4_extract_actions(result)
    summary = step_5_generate_summary(result, actions)
    return summary

# Test the chain
raw_email = """From: john@example.com
Subject: Project Update & Next Steps


Hi Team,

Here's the project update:

Action: Review the design document by Friday
TODO: Schedule client meeting
Please send feedback by EOD

The project is on track.
"""

summary = process_email(raw_email)
print(summary)
# Output: {'sender': 'john@example.com', 'subject': 'Project Update & Next Steps', 'action_items': ['Action: Review the design document by Friday', 'TODO: Schedule client meeting', 'Please send feedback by EOD'], 'word_count': 24}

Performance Considerations

As your linear chains handle more data, performance becomes important. Here are key considerations:

Time Complexity

Linear chains have O(n) time complexity where n is the number of steps. Each step processes the entire input, so total time grows linearly with steps.

Memory Usage

Each step may create new data structures. For large inputs, consider:

  • Processing data in chunks when possible
  • Using generators for large datasets
  • Releasing memory from previous steps when no longer needed
💡 Optimization Tip: Profile your chain to identify bottlenecks. Often, one or two steps consume most of the processing time. Focus optimization efforts there rather than trying to optimize every step equally.

Key Takeaways

  • Linear chains are sequences of steps that execute one after another, forming the foundation of AI agent architectures
  • They consist of input, processing steps, and output - simple but powerful
  • Error handling and logging are essential for production-ready chains
  • Test both individual steps (unit tests) and the full chain (integration tests)
  • Keep chains focused - if they grow too long, consider breaking them into sub-chains
  • Linear chains are deterministic: same input always produces same output
  • Common use cases include data preprocessing, content generation, and report automation
