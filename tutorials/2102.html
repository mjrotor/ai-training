Building a Chain

Learn about building a chain.

What Is a Chain?

So far, you have learned how to call a language model with a prompt and get a response. That is powerful, but it is only the beginning. A single call to a language model is like a single sentence in a conversation. To build something truly useful, you need to chain multiple steps together — passing the output of one step as the input to the next.

A chain is simply a sequence of operations where each step builds on the result of the previous one. Think of it like an assembly line in a factory: raw materials enter at one end, and at each station, a worker adds something or transforms the product until a finished item comes out the other side.

Why Chains Matter

Real-world tasks are rarely solved in a single step. Consider a customer support bot that needs to:

  1. Classify the customer's question
  2. Retrieve relevant documentation
  3. Generate a helpful response
  4. Format the response for the chat interface

Each of these is a distinct step, and each depends on the result of the one before it. Chains let you compose these steps into a single, reliable pipeline.

Key Concept: A chain is a sequence of callable components (LLM calls, tools, data transformations) linked together so that the output of one becomes the input of the next.

The Simplest Chain: Prompt → LLM → Output

The most basic chain has three parts:

  • Input / Prompt Template — A structured prompt with placeholders for variables.
  • Language Model — The LLM that processes the prompt.
  • Output Parser — A function that extracts and formats the result.

Here is a minimal example using LangChain:

from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

# Step 1: Define the prompt template
prompt = ChatPromptTemplate.from_template(
    "What is a good name for a company that makes {product}?"
)

# Step 2: Create the language model
model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# Step 3: Chain them together using the pipe operator
chain = prompt | model

# Step 4: Invoke the chain with an input
response = chain.invoke({"product": "colorful socks"})
print(response.content)

The pipe operator | is LangChain's way of saying "take the output of the left side and feed it into the right side." This is the fundamental building block of every chain you will ever build.

Adding an Output Parser

By default, the model returns an AIMessage object. Often you want plain text, a number, or structured data. An output parser handles this conversion for you.

from langchain_core.output_parsers import StrOutputParser

# Build the chain with an output parser
chain = prompt | model | StrOutputParser()

# Now the result is a plain string
result = chain.invoke({"product": "colorful socks"})
print(result)  # e.g., "Rainbow Threads"
Tip: Always add an output parser to your chains. It keeps the rest of your code clean and makes it easy to swap models later without changing downstream logic.

Multi-Step Chains

Now let us build something more interesting: a chain that takes a topic, generates a blog post outline, and then writes a full paragraph for each section.

from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# Step 1: Generate an outline
outline_prompt = ChatPromptTemplate.from_template(
    "Write a 3-point blog post outline about {topic}. "
    "Return each point on its own line starting with 'Section: '."
)
outline_chain = outline_prompt | model | StrOutputParser()

# Step 2: Expand the outline into paragraphs
expand_prompt = ChatPromptTemplate.from_template(
    "Given this blog outline:\n{outline}\n\n"
    "Write one paragraph for each section. Label each paragraph "
    "with the section header."
)
expand_chain = expand_prompt | model | StrOutputParser()

# Combine into a single chain
full_chain = {"outline": outline_chain} | expand_chain

result = full_chain.invoke({"topic": "AI in healthcare"})
print(result)

Notice how the first chain produces an outline, and that outline is automatically passed as the outline variable to the second prompt. The dictionary {"outline": outline_chain} maps the output of the first chain to the input expected by the second.

Sequential vs. Parallel Execution

Chains can run steps in different ways:

Execution Type Description When to Use
Sequential Steps run one after another. Each step depends on the previous output. When later steps need earlier results (e.g., outline → full post).
Parallel Multiple steps run at the same time using the same input. When steps are independent (e.g., generate title and summary simultaneously).
Branching A step decides which path to take next based on the output. When the flow depends on conditions (e.g., classify question type first).

Parallel Example

Here is how you can run two chains in parallel using RunnableParallel:

from langchain_core.runnables import RunnableParallel

title_prompt = ChatPromptTemplate.from_template(
    "Write a catchy title for a blog post about {topic}."
)
summary_prompt = ChatPromptTemplate.from_template(
    "Write a one-sentence summary for a blog post about {topic}."
)

title_chain = title_prompt | model | StrOutputParser()
summary_chain = summary_prompt | model | StrOutputParser()

parallel = RunnableParallel(
    title=title_chain,
    summary=summary_chain
)

result = parallel.invoke({"topic": "AI in healthcare"})
print(result["title"])
print(result["summary"])
Watch Out: Parallel chains receive the same input. If you need to pass different inputs to each branch, build separate chains and combine their results manually.

Chains vs. Agents

You might be wondering how chains differ from agents. Here is the distinction:

  • Chains follow a predetermined sequence. You know every step in advance.
  • Agents use the LLM to decide what to do next at each step. The flow is dynamic.

Chains are predictable, easier to debug, and cheaper to run. Agents are more flexible but harder to control. In practice, most production systems use both: chains for well-defined pipelines and agents for tasks that require reasoning and tool use.

Rule of Thumb: If you can write down the steps on paper, use a chain. If the steps depend on what the model discovers along the way, use an agent.

Coding Exercise

Exercise

Build a two-step chain that:

  1. Takes a book title as input and generates a one-sentence plot summary.
  2. Takes that plot summary and generates three discussion questions for a book club.

Use ChatPromptTemplate, ChatOpenAI, and StrOutputParser. Print only the final discussion questions.

from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# Step 1: Generate a plot summary from the title
summary_prompt = ChatPromptTemplate.from_template(
    "Write a one-sentence plot summary for the book '{title}'."
)
summary_chain = summary_prompt | model | StrOutputParser()

# Step 2: Generate discussion questions from the summary
questions_prompt = ChatPromptTemplate.from_template(
    "Based on this plot summary:\n{summary}\n\n"
    "Write three thought-provoking discussion questions for a book club. "
    "Number them 1, 2, and 3."
)
questions_chain = questions_prompt | model | StrOutputParser()

# Combine the chains
full_chain = {"summary": summary_chain} | questions_chain

# Run it
result = full_chain.invoke({"title": "1984"})
print(result)

Debugging Your Chains

When a chain does not produce the expected output, it can be hard to tell which step went wrong. Here are some strategies:

  1. Test each step individually. Invoke each sub-chain on its own before combining them.
  2. Use RunnablePassthrough to inspect intermediate values.
  3. Enable verbose logging to see every input and output.
from langchain_core.runnables import RunnablePassthrough

# This chain passes data through while also printing it
debug_chain = (
    RunnablePassthrough.assign(
        summary=summary_chain
    )
    | RunnablePassthrough.assign(
        questions=questions_chain
    )
)

# You can also set langchain.verbose = True globally
import langchain
langchain.verbose = True
Pro Tip: When building complex chains, start with the last step and work backward. Make sure each step produces exactly what the next step expects. This "reverse engineering" approach saves hours of debugging.

Key Takeaways

  • A chain is a sequence of callable components where the output of one step feeds into the next.
  • The pipe operator | is the simplest way to connect steps in LangChain.
  • Output parsers like StrOutputParser convert raw model responses into usable formats.
  • Chains can run steps sequentially, in parallel, or with branching logic.
  • Use chains when the steps are known in advance; use agents when the flow must be decided at runtime.
  • Always test each step of a chain individually before combining them into a pipeline.
  • LangChain's RunnableParallel and RunnablePassthrough utilities make it easy to build complex workflows.
