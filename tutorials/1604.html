Negotiation & Consensus

Learn about negotiation & consensus.

What Is Negotiation in Multi-Agent Systems?

When multiple AI agents work together, they often need to negotiate — that is, communicate and make decisions collectively to reach a shared goal. Just like humans in a team meeting, agents may have different opinions, priorities, or information. Negotiation helps them resolve conflicts and agree on a plan.

In AI, negotiation is not about arguing — it's about structured communication that leads to consensus, where all agents agree on a course of action.

Why Do Agents Need to Negotiate?

Imagine two delivery drones trying to deliver packages in the same area. If they don't coordinate, they might:

  • Fly into each other
  • Deliver to the wrong address
  • Waste time and energy

By negotiating, they can agree on who goes where, when, and how — making the whole system more efficient and safe.

💡 Key Idea: Negotiation allows agents to share information, resolve conflicts, and make better group decisions.

Types of Negotiation

There are several common negotiation strategies used in multi-agent systems:

Strategy Description Best For
Voting Agents vote on options; majority wins Simple decisions with clear choices
Bargaining Agents trade offers until agreement Resource allocation, task assignment
Mediation A neutral agent helps resolve conflict Complex disputes with many parties
Consensus All agents must agree before acting High-stakes or safety-critical tasks

How Consensus Works

Consensus means that all agents agree on a decision. It’s like a team vote where everyone must say “yes” before moving forward.

One common method is the Byzantine Fault Tolerance (BFT) protocol, which ensures agreement even if some agents are faulty or malicious.

✅ Tip: Consensus is slower than voting, but much more reliable for critical decisions.

Example: Voting-Based Consensus in Python

Let’s simulate a simple voting system where agents vote on a task assignment.

class Agent:
    def __init__(self, name, preference):
        self.name = name
        self.preference = preference  # e.g., "Task A" or "Task B"

    def vote(self, options):
        # Vote for preferred option if available
        if self.preference in options:
            return self.preference
        else:
            return options[0]  # Default to first option

def run_consensus(agents, options):
    votes = {}
    for agent in agents:
        vote = agent.vote(options)
        votes[vote] = votes.get(vote, 0) + 1

    # Find the option with most votes
    winner = max(votes, key=votes.get)
    return winner, votes

# Example usage
agents = [
    Agent("Drone 1", "Task A"),
    Agent("Drone 2", "Task B"),
    Agent("Drone 3", "Task A"),
    Agent("Drone 4", "Task A")
]

options = ["Task A", "Task B"]
winner, vote_count = run_consensus(agents, options)

print(f"Winner: {winner}")
print(f"Vote counts: {vote_count}")

This code creates agents with preferences and runs a simple majority vote. The option with the most votes wins.

⚠️ Warning: Majority voting can fail if agents have very different priorities. Always consider fairness and context!

Building a Bargaining Protocol

In bargaining, agents make offers and counteroffers until they agree. Here’s a simplified version:

def bargain(agent1, agent2, max_rounds=5):
    offer1 = agent1.initial_offer()
    offer2 = agent2.initial_offer()

    for round in range(max_rounds):
        print(f"Round {round+1}: Agent 1 offers {offer1}, Agent 2 offers {offer2}")

        if offer1 == offer2:
            print("Agreement reached!")
            return offer1

        # Agents adjust offers slightly
        offer1 = adjust_offer(offer1, offer2)
        offer2 = adjust_offer(offer2, offer1)

    print("No agreement reached.")
    return None

def adjust_offer(current, other):
    # Simple strategy: move halfway toward the other agent's offer
    return (current + other) / 2

# Example usage
class BargainingAgent:
    def __init__(self, initial):
        self.initial = initial

    def initial_offer(self):
        return self.initial

agent_a = BargainingAgent(100)
agent_b = BargainingAgent(200)

result = bargain(agent_a, agent_b)

This shows how two agents can gradually converge on a shared value through repeated offers.

When to Use Which Strategy?

Choosing the right negotiation method depends on:

  • Speed vs. Accuracy: Voting is fast; consensus is accurate.
  • Number of Agents: Mediation works well with many agents.
  • Stakes: Use consensus for safety-critical decisions.
Exercise

Modify the voting example above to implement a weighted voting system where some agents have more influence (e.g., based on experience or reliability). Each agent should have a weight attribute, and votes should be counted by weight, not just count.

Test it with at least 3 agents with different weights and preferences.

class WeightedAgent:
    def __init__(self, name, preference, weight=1.0):
        self.name = name
        self.preference = preference
        self.weight = weight

    def vote(self, options):
        if self.preference in options:
            return self.preference
        return options[0]

def run_weighted_consensus(agents, options):
    weighted_votes = {}
    for agent in agents:
        vote = agent.vote(options)
        weighted_votes[vote] = weighted_votes.get(vote, 0) + agent.weight

    winner = max(weighted_votes, key=weighted_votes.get)
    return winner, weighted_votes

# Example
agents = [
    WeightedAgent("Drone 1", "Task A", weight=2.0),
    WeightedAgent("Drone 2", "Task B", weight=1.0),
    WeightedAgent("Drone 3", "Task A", weight=1.5)
]

options = ["Task A", "Task B"]
winner, votes = run_weighted_consensus(agents, options)
print(f"Winner: {winner}")
print(f"Weighted votes: {votes}")

Key Takeaways

  • Negotiation helps agents resolve conflicts and make group decisions.
  • Voting is fast but may not always be fair; consensus is reliable but slower.
  • Bargaining allows agents to gradually converge on agreement.
  • Choose the right strategy based on speed, fairness, and stakes.
  • Weighted voting can reflect agent reliability or experience.
