Your First Agent Plan

Learn about your first agent plan.

What Is an Agent Plan?

Before you can build an AI agent, you need a plan. An agent plan is a structured outline that defines what your agent will do, how it will do it, and what tools it will use. Think of it like a recipe: you list the ingredients (tools), the steps (actions), and the expected outcome (goal).

Without a plan, your agent is just a chatbot that responds to prompts. With a plan, it becomes a goal-oriented system that can reason, act, and adapt.

Key Idea: An agent plan is not code yet. It's a blueprint. You'll write it in plain language first, then translate it into code later.

Why Plan Before You Code?

Planning saves time and prevents confusion. Here's why:

  • Clarity: You know exactly what your agent needs to accomplish.
  • Modularity: You can break complex tasks into smaller, manageable steps.
  • Debugging: If something goes wrong, you can trace the issue back to a specific step in your plan.
  • Reusability: A good plan can be reused or adapted for similar agents.

The Anatomy of an Agent Plan

Every agent plan has four core components:

1. Goal

The goal is the end result your agent is trying to achieve. It should be specific and measurable.

Example: "Summarize the top 3 news articles about AI from today."

2. Tools

Tools are the external services or functions your agent can use to achieve its goal. These might include:

  • Web search APIs
  • File readers
  • Databases
  • Code interpreters

3. Steps

Steps are the sequence of actions your agent takes to reach the goal. Each step should be atomic—meaning it does one thing only.

4. Output

The output is what the agent returns to the user. It could be text, a file, a chart, or even another action.

Example: A Simple Research Agent Plan

Let's walk through a real example. Suppose you want an agent that finds and summarizes recent news about climate change.


# Agent Plan: Climate News Summarizer

## Goal
Summarize the top 5 recent news articles about climate change.

## Tools
- web_search(query: str) -> list[dict]
- summarize(text: str) -> str

## Steps
1. Use web_search to find recent articles about "climate change"
2. Extract the content of the top 5 results
3. Use summarize on each article
4. Combine summaries into a single report

## Output
A formatted report with 5 bullet-point summaries.
Pro Tip: Always start with the goal. If you can't state the goal clearly, your plan isn't ready.

Planning vs. Coding: A Comparison

It's important to understand the difference between planning and coding. Here's a quick comparison:

Aspect Planning Coding
Focus What the agent should do How the agent does it
Language Plain English or pseudocode Python, JavaScript, etc.
Audience You, your team, stakeholders The computer
Flexibility Easy to change Harder to refactor

Common Mistakes in Agent Planning

Beginners often make these mistakes when creating their first agent plan:

  • Vague goals: "Do something useful" is not a goal. Be specific.
  • Too many steps: If your plan has more than 7 steps, break it into sub-agents.
  • Missing tools: Don't assume your agent can do everything. List every tool it needs.
  • No error handling: What happens if a tool fails? Plan for it.
Warning: Never skip the planning phase. Jumping straight into code leads to messy, unmaintainable agents.

Your First Coding Exercise

Now it's your turn! Create a plan for an agent that helps users find recipes based on ingredients they have at home.

Exercise: Recipe Finder Agent Plan

Write a plan for a Recipe Finder Agent. Your plan should include:

  • A clear goal
  • At least 2 tools
  • 3-5 steps
  • A defined output

Use the same format as the Climate News Summarizer example above.


# Agent Plan: Recipe Finder

## Goal
Find 3 recipes that use ingredients the user already has at home.

## Tools
- search_recipes(ingredients: list[str]) -> list[dict]
- get_recipe_details(recipe_id: str) -> dict

## Steps
1. Ask the user what ingredients they have
2. Use search_recipes with the ingredient list
3. Get details for the top 3 results
4. Format the recipes with title, ingredients, and instructions
5. Return the formatted list

## Output
A numbered list of 3 recipes, each with:
- Recipe name
- Required ingredients
- Step-by-step instructions

Key Takeaways

  • An agent plan is a blueprint, not code.
  • Every plan needs a goal, tools, steps, and output.
  • Planning before coding saves time and reduces errors.
  • Keep steps atomic and goals specific.
  • Always consider what happens if a tool fails.
