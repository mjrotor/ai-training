Metadata Filtering

Learn about metadata filtering.

What Is Metadata Filtering?

Metadata filtering is the process of narrowing down a collection of items—such as documents, database records, or tool definitions—based on structured attributes (metadata) attached to each item, rather than searching through the full content itself. In the context of AI agents, metadata filtering is essential for efficiently selecting relevant tools, documents, or data sources before performing expensive operations like full-text search or LLM inference.

Think of it like a library catalog: instead of reading every book to find one about "machine learning published after 2020," you filter by subject, publication year, and author first. Metadata filtering gives your AI agent the same efficiency.

Why Metadata Filtering Matters for AI Agents

AI agents often have access to dozens or even hundreds of tools, documents, or data sources. Without metadata filtering, the agent would need to process all of them for every query—wasting tokens, increasing latency, and reducing accuracy. By filtering first, you:

  • Reduce token usage by sending only relevant items to the LLM.
  • Improve response accuracy by eliminating irrelevant context.
  • Speed up execution by avoiding unnecessary tool calls or searches.
  • Enable dynamic tool selection based on user permissions, task type, or environment.
Note: Metadata filtering is often used before semantic search or LLM reasoning. It acts as a fast, deterministic pre-filter that reduces the search space.

Common Metadata Attributes

Metadata can include any structured attribute that describes an item. Here are common examples:

Attribute Description Example Value
type Category or kind of item "tool", "document", "dataset"
domain Subject area or application domain "finance", "healthcare", "engineering"
version Version or revision number "v2.1", "2024-03"
access_level Required permission level "public", "internal", "admin"
tags List of descriptive keywords ["search", "real-time", "api"]
created_at Creation or update timestamp "2024-01-15T10:30:00Z"

Implementing Metadata Filtering in Python

Let's walk through a practical example: filtering a list of tool definitions based on metadata before passing them to an AI agent.

Step 1: Define Tools with Metadata

tools = [
    {
        "name": "search_web",
        "description": "Search the web for current information.",
        "metadata": {
            "type": "tool",
            "domain": "general",
            "access_level": "public",
            "tags": ["search", "real-time", "api"]
        }
    },
    {
        "name": "query_database",
        "description": "Run SQL queries on the internal database.",
        "metadata": {
            "type": "tool",
            "domain": "data",
            "access_level": "internal",
            "tags": ["database", "sql", "internal"]
        }
    },
    {
        "name": "send_email",
        "description": "Send an email to a specified recipient.",
        "metadata": {
            "type": "tool",
            "domain": "communication",
            "access_level": "public",
            "tags": ["email", "communication", "outbound"]
        }
    },
    {
        "name": "generate_report",
        "description": "Generate a PDF report from data.",
        "metadata": {
            "type": "tool",
            "domain": "data",
            "access_level": "admin",
            "tags": ["report", "pdf", "export"]
        }
    }
]

Step 2: Write a Filter Function

def filter_tools(tools, filters):
    """
    Filter a list of tools based on metadata criteria.
    
    Args:
        tools: List of tool dictionaries with 'metadata' key.
        filters: Dictionary of metadata key-value pairs to match.
                 For list values (like tags), checks for intersection.
    
    Returns:
        List of tools matching all filter criteria.
    """
    filtered = []
    for tool in tools:
        match = True
        for key, value in filters.items():
            meta_value = tool.get("metadata", {}).get(key)
            
            if meta_value is None:
                match = False
                break
            
            # Handle list-type metadata (e.g., tags)
            if isinstance(meta_value, list) and isinstance(value, list):
                if not set(value).intersection(meta_value):
                    match = False
                    break
            elif isinstance(meta_value, list):
                if value not in meta_value:
                    match = False
                    break
            else:
                if meta_value != value:
                    match = False
                    break
        
        if match:
            filtered.append(tool)
    
    return filtered

Step 3: Apply Filters

# Example 1: Get all public tools
public_tools = filter_tools(tools, {"access_level": "public"})
print("Public tools:", [t["name"] for t in public_tools])
# Output: ['search_web', 'send_email']

# Example 2: Get tools in the 'data' domain
data_tools = filter_tools(tools, {"domain": "data"})
print("Data tools:", [t["name"] for t in data_tools])
# Output: ['query_database', 'generate_report']

# Example 3: Get tools with 'search' tag
search_tools = filter_tools(tools, {"tags": ["search"]})
print("Search tools:", [t["name"] for t in search_tools])
# Output: ['search_web']

# Example 4: Combine multiple filters
admin_data_tools = filter_tools(tools, {
    "access_level": "admin",
    "domain": "data"
})
print("Admin data tools:", [t["name"] for t in admin_data_tools])
# Output: ['generate_report']
Tip: Use multiple filter criteria together to narrow results precisely. The order of filters doesn't matter—all conditions must be met (logical AND).

Advanced Filtering Patterns

Range and Comparison Filters

For numeric or date-based metadata, you often need comparison operators instead of exact matches:

def filter_by_range(items, key, min_val=None, max_val=None):
    """Filter items where min_val <= metadata[key] <= max_val."""
    results = []
    for item in items:
        value = item.get("metadata", {}).get(key)
        if value is None:
            continue
        if min_val is not None and value < min_val:
            continue
        if max_val is not None and value > max_val:
            continue
        results.append(item)
    return results

# Example: Filter tools created after a certain date
recent_tools = filter_by_range(tools_with_dates, "created_at", min_val="2024-01-01")

Nested Metadata Filtering

Sometimes metadata is nested. Use dot notation or recursive access:

def get_nested(data, path):
    """Access nested dictionary keys using dot-separated path."""
    keys = path.split(".")
    current = data
    for key in keys:
        if isinstance(current, dict):
            current = current.get(key)
        else:
            return None
    return current

# Example: Filter by nested metadata like "config.max_tokens"
filtered = [
    t for t in tools
    if get_nested(t, "metadata.config.max_tokens") == 4096
]
Warning: Always validate metadata structure before filtering. Missing keys or unexpected types can cause runtime errors. Use .get() with defaults to handle missing data gracefully.

Integration with AI Agent Frameworks

In real AI agent systems, metadata filtering is typically integrated into the tool selection pipeline:

  1. Load all available tools/documents with their metadata.
  2. Apply metadata filters based on user context, permissions, or task requirements.
  3. Optionally apply semantic search on the reduced set for further relevance ranking.
  4. Pass filtered items to the LLM for final selection or execution.
class ToolRegistry:
    def __init__(self, tools):
        self.tools = tools
    
    def get_available_tools(self, user_context):
        """Return tools available to the user based on their context."""
        # Step 1: Filter by access level
        access_filter = {"access_level": user_context["access_level"]}
        accessible = filter_tools(self.tools, access_filter)
        
        # Step 2: Filter by user's department/domain
        if user_context.get("domain"):
            domain_filter = {"domain": user_context["domain"]}
            accessible = filter_tools(accessible, domain_filter)
        
        return accessible

# Usage
registry = ToolRegistry(tools)
user = {"access_level": "internal", "domain": "data"}
available = registry.get_available_tools(user)
print([t["name"] for t in available])  # ['query_database']

Performance Considerations

Approach Best For Time Complexity
Linear scan with filter_tools() Small collections (< 1000 items) O(n)
Indexed lookup (e.g., dictionary by key) Frequent queries on same attribute O(1) per lookup
Database query (SQL/NoSQL) Large collections, complex filters Varies (uses DB indexes)
Vector DB with metadata filters Hybrid search (semantic + metadata) Optimized by DB engine
Note: For production systems with thousands of tools or documents, consider using a database or vector store (like Pinecone, Weaviate, or ChromaDB) that supports native metadata filtering.
Exercise: Build a Document Filter

You have a list of documents with metadata. Write a function filter_documents(documents, required_tags, min_word_count) that returns documents matching ALL of the following criteria:

  • Document has ALL tags in required_tags (not just any one).
  • Document's word_count is at least min_word_count.

Use this sample data:

documents = [
    {"title": "AI Basics", "metadata": {"tags": ["ai", "intro"], "word_count": 1500}},
    {"title": "Advanced ML", "metadata": {"tags": ["ai", "ml", "advanced"], "word_count": 3000}},
    {"title": "Python Guide", "metadata": {"tags": ["python", "intro"], "word_count": 2000}},
]

Expected result for filter_documents(documents, ["ai"], 2000) should return only "Advanced ML".

def filter_documents(documents, required_tags, min_word_count):
    results = []
    for doc in documents:
        meta = doc.get("metadata", {})
        tags = meta.get("tags", [])
        word_count = meta.get("word_count", 0)
        
        # Check if ALL required tags are present
        has_all_tags = all(tag in tags for tag in required_tags)
        
        # Check word count threshold
        meets_length = word_count >= min_word_count
        
        if has_all_tags and meets_length:
            results.append(doc)
    
    return results

# Test
docs = [
    {"title": "AI Basics", "metadata": {"tags": ["ai", "intro"], "word_count": 1500}},
    {"title": "Advanced ML", "metadata": {"tags": ["ai", "ml", "advanced"], "word_count": 3000}},
    {"title": "Python Guide", "metadata": {"tags": ["python", "intro"], "word_count": 2000}},
]

result = filter_documents(docs, ["ai"], 2000)
print([d["title"] for d in result])  # ['Advanced ML']

Key Takeaways

  • Metadata filtering uses structured attributes to narrow down items before expensive operations like LLM inference or full-text search.
  • Common metadata attributes include type, domain, access_level, tags, and timestamps.
  • Implement filtering functions that handle exact matches, list intersections, and range comparisons.
  • Always validate metadata structure to avoid runtime errors from missing keys or unexpected types.
  • Integrate metadata filtering into your agent's tool selection pipeline for better performance and accuracy.
  • For large-scale systems, use databases or vector stores with native metadata filtering support.
