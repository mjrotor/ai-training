Prompt Engineering Anti-Patterns

Learn about prompt engineering anti-patterns.

What Are Prompt Engineering Anti-Patterns?

Welcome to Day 3, Lesson 5! So far, you've learned how to write effective prompts and structure conversations with AI agents. But sometimes, even well-intentioned prompts can lead to poor results. These common mistakes are called anti-patterns — patterns that seem helpful but actually hurt your AI's performance.

In this lesson, we'll explore the most common prompt engineering anti-patterns, why they happen, and how to fix them. By the end, you'll be able to spot these issues in your own prompts and write cleaner, more effective instructions for your AI agents.

The Top 5 Prompt Engineering Anti-Patterns

Let's dive into the five most common mistakes people make when writing prompts for AI agents. Each one comes with a real-world example and a better alternative.

1. The "Kitchen Sink" Prompt

This happens when you try to cram too many instructions into a single prompt. The AI gets confused about what's most important and may ignore key details.

# ❌ Anti-Pattern: Kitchen Sink Prompt
prompt = """
You are a helpful assistant. You should be friendly and professional. 
You need to answer questions about Python, JavaScript, and SQL. 
Also, you should format your responses in markdown. 
Don't use jargon. Keep answers under 200 words. 
If you don't know something, say so. 
Always end with a follow-up question. 
Remember to be concise but thorough.
"""

# ✅ Better: Focused, Structured Prompt
prompt = """
You are a Python tutor. Your job is to explain concepts clearly.

Rules:
- Use simple language, no jargon
- Keep answers under 200 words
- End with one follow-up question

If you don't know something, say "I'm not sure about that."
"""
Warning: When you overload a prompt with too many rules, the AI may prioritize the wrong ones or ignore them entirely. Keep your prompts focused on one clear goal.

2. Vague or Ambiguous Instructions

Using words like "good," "nice," or "appropriate" without defining them leaves too much room for interpretation. The AI doesn't know what "good" means to you.

# ❌ Anti-Pattern: Vague Instructions
prompt = "Write a good email to my boss."

# ✅ Better: Specific Instructions
prompt = """
Write a professional email to my manager requesting a day off.

Include:
- Date of absence: March 15, 2025
- Reason: Personal appointment
- Offer to complete urgent tasks before leaving
- Keep tone polite and concise (under 100 words)
"""

3. Assuming Context the AI Doesn't Have

Sometimes we write prompts as if the AI already knows our situation, project details, or previous conversations. But each prompt starts fresh unless you provide that context.

# ❌ Anti-Pattern: Missing Context
prompt = "Fix the bug in my code."

# ✅ Better: Provide Full Context
prompt = """
I'm building a Flask web app. Users report a 500 error when submitting the login form.

Here's the relevant code:

@app.route('/login', methods=['POST'])
def login():
    username = request.form['username']
    password = request.form['password']
    user = User.query.filter_by(username=username).first()
    if user.password == password:
        return redirect('/dashboard')
    return 'Invalid credentials', 401

The error occurs on line 6. What's wrong and how do I fix it?
"""
Tip: Always ask yourself: "If someone read this prompt with zero knowledge of my project, could they help me?" If not, add more context.

4. Not Defining the Output Format

Without specifying how you want the response structured, the AI might give you a wall of text when you needed a list, or a paragraph when you wanted JSON.

# ❌ Anti-Pattern: No Format Specified
prompt = "Give me a list of Python data types."

# ✅ Better: Specify Output Format
prompt = """
List the 8 basic Python data types.

Format your response as a markdown table with these columns:
- Data Type
- Example
- Mutable (Yes/No)

Sort alphabetically by Data Type.
"""

5. Using Negative Instructions Instead of Positive Ones

Telling the AI what not to do is less effective than telling it what to do. The AI responds better to clear, positive guidance.

# ❌ Anti-Pattern: Negative Instructions
prompt = """
Don't use technical terms.
Don't make it too long.
Don't include code examples.
Don't be boring.
"""

# ✅ Better: Positive Instructions
prompt = """
Explain recursion to a 10-year-old.

Use:
- A simple analogy (like Russian nesting dolls)
- One short code example in Python
- Keep it under 150 words
- Make it fun and engaging
"""
Did you know? Research shows that AI models process positive instructions more reliably than negative ones. Instead of saying "Don't use jargon," say "Use simple words anyone can understand."

Anti-Pattern Comparison Table

Here's a quick reference to help you identify and fix common anti-patterns:

Anti-Pattern Symptom Fix
Kitchen Sink AI ignores key instructions Focus on 3-5 clear rules max
Vague Instructions Response doesn't match expectations Use specific, measurable criteria
Missing Context AI asks for clarification repeatedly Include all relevant background info
No Output Format Response structure is inconsistent Specify format (table, list, JSON, etc.)
Negative Instructions AI still does the thing you didn't want Reframe as positive, actionable guidance

How to Review Your Prompts

Before sending any prompt to an AI agent, run through this quick checklist:

  1. Is it focused? Does it have one clear goal, or am I asking for too much?
  2. Is it specific? Have I defined what "good" looks like with concrete examples or criteria?
  3. Is context included? Does the AI have everything it needs to help me?
  4. Is the format specified? Have I told the AI how to structure its response?
  5. Is it positive? Am I telling the AI what TO do instead of what NOT to do?
Pro Tip: Save your best prompts in a personal "prompt library." When you find a prompt that works well, document it so you can reuse and improve it later.

Practice Exercise

Time to put your knowledge to the test! Let's fix a problematic prompt together.

Exercise: Fix the Anti-Patterns

Below is a prompt with at least 3 anti-patterns. Identify them and rewrite the prompt to fix all issues.

prompt = """
Don't write a long response. I need help with my Python project. 
It's not working right. Fix it. Make it good. 
Also don't use any complicated stuff. 
The code is:

def calculate_average(numbers):
    total = 0
    for num in numbers:
        total += num
    return total / len(numbers)

It crashes sometimes. Help.
"""

Your task:

  • Identify at least 3 anti-patterns in the prompt above
  • Rewrite the prompt to fix all issues
  • Include specific context, clear instructions, and a defined output format

Anti-patterns identified:

  1. Missing context: No description of when it crashes or what error appears
  2. Vague instructions: "Fix it" and "Make it good" are not specific
  3. Negative instructions: "Don't write a long response" and "Don't use complicated stuff"
  4. No output format: Doesn't specify how the fix should be presented

Improved prompt:

prompt = """
I have a Python function that calculates the average of a list of numbers.

The code:
def calculate_average(numbers):
    total = 0
    for num in numbers:
        total += num
    return total / len(numbers)

The problem: It crashes with a ZeroDivisionError when I pass an empty list.

Please:
1. Explain why the error occurs
2. Show the fixed code with a comment explaining the change
3. Suggest one additional improvement for handling edge cases

Keep your response under 200 words.
"""

Key Takeaways

  • Keep prompts focused: One clear goal per prompt leads to better results than trying to do everything at once.
  • Be specific: Replace vague words like "good" or "nice" with concrete, measurable criteria.
  • Provide context: Give the AI all the background information it needs — don't assume it knows your project.
  • Define the format: Tell the AI exactly how you want the response structured (table, list, JSON, etc.).
  • Use positive instructions: Tell the AI what TO do instead of what NOT to do for more reliable results.
  • Review before sending: Use the 5-point checklist to catch anti-patterns before they cause problems.
